> [!NOTE] Description
>  - This is a mod for Fabric Minecraft that will alow players to dynamically chose their "Profiles" while playing in a way that will allow better and more immersive roleplaying in Minecraft. The Idea is to be able to open a gui that's essentially a Profile chooser/editor that lets you pick created profiles that will change your name, skin, chat color, etc to the ones attached to that profile.

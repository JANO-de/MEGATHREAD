## 📦 How to set this up in Obsidian (2 minutes)

  

1. Create a folder structure in your vault:

```

📁 Mangaka/

├─ 🗓️ 00 - Year 1 Schedule.md ← this whole doc goes here

├─ 📓 01 - Session Logs/ ← daily notes live here

├─ 🧠 02 - Study Notes/

└─ ⚙️ Templates/

├─ Daily Art Log.md

└─ Weekly Art Review.md

```

2. Enable **core plugins**: `Settings → Core plugins → Daily notes` + `Templates`. Set Daily notes folder to `01 - Session Logs`, and the template to `Daily Art Log`.

3. Paste the 📓 Daily Art Log template below into `Templates/Daily Art Log.md`, and the 📊 Weekly Review into its own template file.

4. Every morning: open your Daily Note (it auto-fills the template), then work through today's checkbox in this schedule. Tick it when done! ✅

      - Daño Físico y Daño Tóxico.
  - **Absorción:** 7% `〨Hechicería〨`
    - Cada **500%** de **maestría** se añade **+7%**.
  - **Acción Adicional:** 3
- **Naturaleza**
  - **Karma-Mágico:** Entorno
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.

- **Estadísticas**

**Expansión de Dominio: Inversión de Capas Divinas.** El cielo se vuelve enemigo de los presentes, anulando vuelo y levitación. Quienes se separan del suelo pierden su orientación y velocidad, mientras grietas celestiales se forman con cada ataque, explotando todas a la vez cuando el usuario desata **Rompedor de Hielo Fino**.

- **Efectos Adicionales**
  - **Encarcelamiento Absoluto:** Dominio Completo
- **Propiedades**
  - **Rango:** 3 Zonas
  - **Maestría Total:** +400%
    - Aplica a todas las maestrías que estén relacionadas con las habilidades que están vinculadas a tu dominio.
  - **Maldición Celestial**
    - Toda habilidad de levitación, vuelo o desplazamiento aéreo será inhabilitada para todos menos el usuario.
  - **Cambio de Perspectiva**
    - Cuando un objetivo pierde contacto por completo con el suelo este sufre un cambio de perspectiva que le hace ver todo de cabeza.
      - La velocidad del usuario en este estado se contará como si fuese **cero**.
        - **Presión Absoluta**
  - **Fragmentación Universal**
    - Cada vez que se realice un **movimiento ofensivo** aparecerá una **grieta** en el entorno del dominio como contador visual.
      - Esto son acumulaciones que no desaparecen y que se pueden acumular indefinidamente.
      - Estas acumulaciones provocan que cuando el usuario utilice '**Rompedor de Hielo Fino**', esta misma técnica explote varias veces en cadena, se puede repartir entre las siguientes acciones del mismo turno.
  - **Golpe Seguro**
  - **Dominio Completo**
- **Naturaleza**
  - **Karma-Mágico:** Entorno/Potenciación
  - **Elemento:** Ninguno
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Expansión de Dominio**
  - **Puntos de Habilidad:** 7

**Bestia Mítica del Ámbar.** Se reconstruye el cuerpo con energía eléctrica pura: surgiendo un tercer ojo en la frente, cubriendo cada vez más extremidades con llamas de energía maldita electrificada, y las manos cargadas de rayos extremadamente poderosos. Le permite a su vez manifestar ondas sónicas para atacar, rayos electromagnéticos y visión de rayos-X para descifrar al enemigo. Esta forma va mutando cada vez más, proporcionando un aumento en las características constantemente.

- **Estadísticas**
  - **Porcentaje:** 50% x Turno **(General)** `〨Hechicería〨`
- **Efectos Adicionales**
  - **Ruptura Absoluta:** 7 Acciones
    - Se aplicará aunque no haya contacto directo, es suficiente con que choque el golpe con por ejemplo un escudo corporal del objetivo.
  - **Ejecución**
    - Cuando el usuario hace contacto directo con el objetivo pueda desintegrarle extremidades fácilmente con electricidad.
  - **Electrificación Absoluta:** 7 Acciones
- **Propiedades**
  - **Duración:** Combate Completo
  - **Mutación Salvaje**
    - Cada turno que pasa el usuario con esta forma activa se recubre más de electricidad, adquiriendo aumento de capacidades significativamente.
      - **Suma:** 500 x Turno **(???)** `〨Hechicería〨`
  - **Predicción:** 7 x Turno `〨Hechicería〨`
    - **Predicción Absoluta:** 7 x Turno`〨Hechicería〨`
  - **Penetración:** 7% x Turno `〨Hechicería〨`
    - Lo sobrante se volverá **daño crítico**.
  - **Perforación Celestial:** +50% x Turno
  - **Maestría Total:** +350% **(Electricidad)**
  - **Maestría Total:** +350% **(Ruptura)**
  - **Recuperación Total / Resurrección**
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Electricidad
- **Consumo**
  - **Aguante:** 0
    - **Vitalidad:** 100%
  - **CD:** 1 x Combate
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 7

## ᴘᴀꜱɪᴠᴀꜱ

**Energía Maldita Electrificada.** Todas las habilidades de la sub-rama de ‘**Hechicería**' se contarán como habilidades de ‘**Electricidad**’, pudiendo escalar con este mismo elemento.

- **Propiedades**
  - **Maestría Total:** 20% **(Electricidad)**
  - **Maestría Total:** 20% **(Ruptura)**
    - La rama de '**Hechicería**' puede escalar también con estos elementos.
  - **Inmunidad:** Electricidad/Electrificación Absoluta
  - **Electrificación Absoluta:** 7 Acciones
    - Se puede aplicar electrificación en cualquier habilidad de **hechicería**, y el usuario tiene adicionalmente el elemento '**Electricidad**’.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

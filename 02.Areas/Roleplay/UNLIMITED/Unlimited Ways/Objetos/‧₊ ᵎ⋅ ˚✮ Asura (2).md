# ‧₊ ᵎ⋅ ˚✮ Asura (2)

![[image (47).png]]
,![[image (47).png]]

**Asura.** Arma de grado estelar. Aunque sellada la mayor parte del tiempo, incluso así es equivalente a un poder descomunal.

- **Estadísticas**
  - **Suma:** 10.000 **(F. Principal)**
  - **Suma:** 10.000 **(Velocidad)**
- **Efectos Adicionales**
  - **Hemorragia Absoluta:** 7 Acciones
  - **Sangrado Absoluto:** 7 Acciones
- **Propiedades**
  - **Supremacía Absoluta**
  - **Penetración:** 300%
  - **Afinidad de Guerra**
    - Cualquier **Forma/Potenciación** que se base en **potenciarse con el paso del tiempo** se volverá el **doble** de **rápida**.
      - Significando que por ejemplo cada turno, contarían como si hubiesen pasado dos.
      - En **Stampede** permite que cada que se gana una carga por cualquier medio, se ganen **dos**.
    - **Maestría Total:** +35%
      - Aplica a **todas** las **maestrías** del portador.
  - **Reactor Absoluto**
    - Todas las **habilidades** del portador pasarán a tener un **Nivel de Drenaje** de **+10**.
      - Estos niveles **NO** serán afectados por habilidades en las que no se aplique el **Nivel de Drenaje**.
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Armamento:** Espada.
    - **Porcentaje:** +25% **(Fuerza Principal)**
    - **Porcentaje:** +25% **(Velocidad)**
      - **Sangrado:** +50%

# ₊⊹ Runa del Progreso

![[1628a18c58f93892ab217b7c033884d5.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Runa del Progreso.** Esta es una runa que se mantiene siempre con el usuario, le permite tener avances significativamente más altos de lo usual.

- **Propiedades**
  - **Experiencia:** +x1
  - **Puntos de Habilidad:** +x1
  - **Entrenamientos de Maestría Avanzados**
    - El usuario recibirá **maestría** adicional tras cada entrenamiento de la misma.
      - **Maestría:** +10%
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0

# ₊⊹ Phoenix Down (🔮)

![[b329b70b571a63d873b7e7fc8177155e.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Phoenix Down.** Se dice que son fragmentos perdidos de las llamas de un fénix. Cuando este objeto es utilizado, el usuario adquiere una **vida extra** de un solo uso. El objeto además de salvar al usuario de la muerte, lo teletransporta a una ubicación segura.

- **Propiedades**
  - **Resurrección / Recuperación Total**
    - No se puede anular la **vida extra**.
      - **Teletransporte Absoluto**
        - **Ignora:** Encarcelamiento Absoluto
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0

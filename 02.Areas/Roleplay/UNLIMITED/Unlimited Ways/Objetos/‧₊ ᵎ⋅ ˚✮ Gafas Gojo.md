**Gafas Gojo.** Esto son unas gafas o venda con la capacidad de suprimir el poder de los '**Seis Ojos**'. Lo que permitirá calmar esta misma habilidad sin tener que estar forzando constantemente las energías. Solo puedes tener una de las dos puesta a la vez.

- **Estadísticas**
  - **Porcentaje:** 50% **(General)**
    - Al quitarse este accesorio se obtiene.
      - **Duración:** Combate Completo
- **Propiedades**
  - **Maestría Total:** +35% **(Hechicería)**
  - **Maestría Total:** +35% **(Mago)**
  - **Maestría Total:** +35% **(Brujo)**
    - Al quitarse este accesorio se obtiene.
      - **Duración:** Combate Completo
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Equipamiento:** Accesorio.

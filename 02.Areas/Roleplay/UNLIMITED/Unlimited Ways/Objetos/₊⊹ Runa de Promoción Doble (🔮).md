# ₊⊹ Runa de Promoción Doble (🔮)

![[a9c36f0aec574ef3d49de1a6b3282a65.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Runa de Promoción Doble.** Esta es una runa especial capaz de proporcionar al usuario **dos subidas de Rango de Aventurero**, adquiriendo en el proceso las condiciones necesarias para esto. Esta runa también puede utilizarse en **objetos** para elevar el rango de los mismos gratuitamente.

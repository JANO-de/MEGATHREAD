# ₊⊹ Medicina Demoníaca (🔮)

![[e794bb2c91ec3bd636090bd17b7dae65.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Medicina Demoníaca.** Es una medicina especial que sirve para eliminar las debilidades de ser un ‘**Demonio de KNY**'/'**Vampiro de JoJo’s**' o para cambiar/eliminar clanes o razas. Puede proporcionar ser un '**Demonio de KNY**’. También puede usarse para **removerse un Stand**, si divides la medicina en dos y te la tomas junto a otra persona que posee un **Stand**, los intercambiaréis.

- **Propiedades**
  - **Cura Demoníaca**
    - El consumidor puede elegir entre eliminar las **debilidades** que le proporciona la raza de '**Demonio KNY**' o quitarse una **raza/clan secundario**. También sirve para quitarse **Chosens**. También puede utilizarse para cambiarse el **Clan** o **Raza** de **origen**.
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 7 Días
    - El CD es individual para cada slot.
- **Requisitos del Objeto**
  - **Creación**
    - **Lirio de Araña Azul:** 60

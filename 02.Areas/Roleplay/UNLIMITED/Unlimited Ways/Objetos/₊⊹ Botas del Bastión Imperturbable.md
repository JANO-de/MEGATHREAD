# ₊⊹ Botas del Bastión Imperturbable

![[833d13b6ae5a58aa67202ef7689ed0d5.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Botas del Bastión Imperturbable.** Unas botas que forman parte de un mismo set pesado.

- **Estadísticas**
  - **Porcentaje:** 20% **(Resistencia)**
- **Propiedades**
  - **Inmunidad:** Quiebre Absoluto
  - **Reducción de Daño:** 2.000
  - **Habilidad de Set:** Muralla Fija
    - Cuando las **cuatro** piezas de **equipamiento** pertenecientes a este set están equipadas, el portador adquiere los siguientes beneficios:
      - **Endurecimiento Absoluto**
      - **Inmunidad:** Repulsión/Atracción
        - Si ya tenías estas inmunidades, se juntan y se vuelven **absolutas**.
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Equipamiento:** Botas.
- **Requisitos del Objeto**
  - **Mejoras**
    - **Pelaje Umbrío:** 5
    - **Acero:** 5

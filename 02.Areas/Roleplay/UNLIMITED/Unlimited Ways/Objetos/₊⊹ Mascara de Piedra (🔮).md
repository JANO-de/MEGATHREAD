# _**¿Cómo se obtiene?**_

Cuando se completa una **Misión de Botanista**, para recolectar plantas. Cada vez que excaves el suelo con una pala de **categoría máxima**, puedes tirar adicionalmente un **1d100**. El cual, si te sale un **100**, te entregará la mascara. El dado solo aplica si la **narración** es de al menos **calidad media**.

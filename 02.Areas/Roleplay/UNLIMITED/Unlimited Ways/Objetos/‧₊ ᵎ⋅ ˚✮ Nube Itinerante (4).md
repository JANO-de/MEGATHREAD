**Nube Itinerante.** Bastón rojo formado por tres segmentos metálicos unidos con un núcleo interno flexible. Este bastón tiene la capacidad de combinar todas las estadísticas del usuario a excepción de **F. Karma** para realizar sus ataques.

- **Estadísticas**
  - **Suma:** 10.000 **(F. Física)**
  - **Suma:** 10.000 **(Velocidad)**
- **Efectos Adicionales**
  - **Contusión Absoluta:** 7 Acciones
- **Propiedades**
  - **Combinación Total**
    - Siempre que se utilice esta arma para movimientos ofensivos, se contará como si **todas** las **estadísticas** a **excepción de F. Karma** fuesen **una sola**.
  - **Maestría Total:** +35% **(???)**
    - Aplica a todas las **técnicas** de naturaleza **física**.
  - **Supremacía Absoluta**
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Armamento:** Bastón.
    - **Porcentaje:** +30% **(Fuerza Principal)**
    - **Porcentaje:** +20% **(Velocidad)**
      - **Supremacía**
      - **Sangrado:** +20%

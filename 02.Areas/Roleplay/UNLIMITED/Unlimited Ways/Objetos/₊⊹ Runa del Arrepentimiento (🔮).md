# ₊⊹ Runa del Arrepentimiento (🔮)

![[1628a18c58f93892ab217b7c033884d5.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Runa del Arrepentimiento.** Esta runa es capaz de reiniciar **cualquier cosa** a elección del usuario. Por ejemplo puede quitarle/cambiarle **clanes/razas**, también es capaz de reiniciar una **maestría** entrenada del usuario para repartirla de forma distinta.

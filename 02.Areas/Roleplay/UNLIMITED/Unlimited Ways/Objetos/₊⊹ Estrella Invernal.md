# ₊⊹ Estrella Invernal

![[99624c8e69f899f278d87c76a611bf0b.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Estrella Invernal.** Un arco capaz de elevar al contacto las propiedades relacionadas a este mismo.

- **Estadísticas**
  - **Suma:** 1.500 **(F. Karma)**
  - **Suma:** 1.500 **(Velocidad)**
- **Efectos Adicionales**
  - **Congelación:** 3 Acciones
- **Propiedades**
  - **Bendición Invernal**
    - Cuando este arco acierta un ataque en un objetivo que ya estaba **paralizado** o **congelado** desde antes, puede elevar esto a otro nivel.
      - **Stun → Silencio → Estasis**
      - **Congelación → Congelación Absoluta**
        - Si el objetivo ya tiene **congelación absoluta**, se le aumentan los **DoT’s** de este efecto en un **+50%** cada vez de forma acumulable hasta que el efecto termine.
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Información del Objeto**
  - **Tipo de Armamento:** Arco.
    - **Porcentaje:** +20% **(Fuerza Principal)**
    - **Porcentaje:** +30% **(Velocidad)**
      - **Congelación:** +100%
- **Requisitos del Objeto**
  - **Mejoras**
    - **Madera de Roble:** 5
    - **Cobre:** 5

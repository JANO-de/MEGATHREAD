# ₊⊹ Grimorio de Saberes Múltiples

![[9cf52a9416c047f4ed5d6da288e6c8e4.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Grimorio de Saberes Múltiples.** Este grimorio eleva todas las maestrías del usuario significativamente y le ayuda a entrenarlas. **(Solo puedes tener una equipada a la vez.)**

- **Estadísticas**
  - **Porcentaje:** 40% **(General)**
- **Propiedades**
  - **Maestría Total:** +30%
    - Aplica a **todas** las **maestrías** del portador.
  - **Maestría Obtenida:** +40%
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Equipamiento:** Accesorio.
- **Requisitos del Objeto**
  - **Mejoras**
    - **Madera de Lignum:** 5
    - **Wolframio:** 5

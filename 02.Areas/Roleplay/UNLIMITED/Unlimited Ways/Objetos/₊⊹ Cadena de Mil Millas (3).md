# ₊⊹ Cadena de Mil Millas (3)

![[2d23ab2e9bc8043b900b3eea7b7a753a.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Cadena de Mil Millas.** Un cadena la cual puede alargarse hasta longitudes indefinidas. Esta arma puede tener varios extremos de unión los cuales sirven para unir dos o más armas al mismo tiempo. **(Esta arma se cuenta como armamento no ocupa slot del mismo.)**

- **Estadísticas**
  - **Suma:** 10.000 **(General)**
- **Efectos Adicionales**
  - **Efectos Adicionales :** +5 Acciones
- **Propiedades**
  - **Rango:** Indefinido
  - **Inmunidad:** Quiebre Absoluto
  - **Unión Múltiple**
    - Todas las armas unidas por esta cadena se contarán como una sola, significando que sin importar con cualquiera ataques, se contará como si utilizases todas al mismo tiempo.
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Información del Objeto**
  - **Tipo de Armamento:** Cadena de Unión.
    - **Porcentaje:** +50% **(General)**
      - **Parálisis:** +50%
- **Requisitos del Objeto**
  - **Mejoras**
    - **Madera de Ébano:** 5
    - **Acero:** 5

**Coraza de Núcleo Arcano.** Una coraza que forma parte de un mismo set mágico.

- **Estadísticas**
  - **Porcentaje:** 20% **(F. Karma)**
- **Propiedades**
  - **Efectos Elementales:** -2 Acciones
  - **Habilidad de Set:** Prioridad de Maná
    - Cuando las **cuatro** piezas de **equipamiento** pertenecientes a este set están equipadas, el portador adquiere los siguientes beneficios:
      - **Aguante:** +x1 **(Pasivo)**
      - **Recuperación de Aguante:** 4.000 x Turno
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Equipamiento:** Torso.
- **Requisitos del Objeto**
  - **Mejoras**
    - **Pelaje Umbrío:** 5
    - **Acero:** 5

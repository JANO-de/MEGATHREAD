# ₊⊹ Runa de Talento (🔮)

![[18e9e4122fb1defa84e5b8114c759579.jpg]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Objetos/image.png]]

**Runa de Talento.** Esta es una runa que solo se puede utilizar **una vez** por **habilidad**. Permite elevar una de dos; El **Rango de Ascensión** de la habilidad para mejorarla de forma general, o puedes elegir una **propiedad/efecto** para **elevarla +1 Tier** respetando limites. (**Máximo dos runas por habilidad.**)

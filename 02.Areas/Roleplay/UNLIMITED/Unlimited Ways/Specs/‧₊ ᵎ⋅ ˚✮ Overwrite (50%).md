# ‧₊ ᵎ⋅ ˚✮ Overwrite (50%)

![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Specs/image.png]]
,![[02.Areas/Roleplay/UNLIMITED/Unlimited Ways/Specs/image.png]]

**Overwrite.** Permite reescribir el código de la realidad al alcance del usuario para dirigirla a su favor. La cantidad de funciones que puede realizar al mismo tiempo es limitada. Solo se puede reescribir aquello con lo que se esté en contacto.

- **Estadísticas**
  - **Suma:** 500 **(???)** `〨???〨`
- **Efectos Adicionales**
  - **Efectos Secundarios**
    - Esto no cuenta como función; cuando el usuario entra en contacto con un objetivo o lo daña, pasivamente aplica estas funciones:
      - **Desvanecimiento Absoluto:** 7 Acciones
      - **Ejecución**
  - **Manipulación de Memoria**
    - Puede reescribir la memoria de un ser vivo para tenerlo bajo su dominio.
      - **Control Mental:** Indefinido
        - **Duración:** 1 Turno Propio `〨???〨`
          - Cada **2.000%** de **maestría** se añade **+1 Turno Propio**.
  - **Corrección de Consecuencia**
    - Puede hacer que las consecuencias del ultimo ataque recibido por sí mismo desaparezcan.
      - Esto incluye efectos, daños y demás.
        - No se puede utilizar si las consecuencias llegaron a un punto de muerte.
  - **Reescritura de Estadísticas**
    - Permite debilitar durante el **combate completo** las capacidades del objetivo.
      - **Reducción de Estadísticas:** 5.000 **(General)** `〨???〨`
- **Propiedades**
  - **Rango:** Contacto Físico **(Overwrite)**
    - También se puede usar a distancia si esas cosas que se quieren reescribir están imbuidas o compuestas por el karma del usuario.
      - Puede modificar el alcance de sus propias habilidades.
        - **Rango:** 7 Zonas
          - **Multi-Target/Semi-AOE/AOE**
  - **Limite:** 1 Función `〨???〨`
    - Esta es la cantidad de funciones que puede realizar al mismo tiempo, no se coloca en CD hasta finalizar la acción en cuestión. Puedes repetir la misma función para ir acumulándola.
      - Cada **1.000%** de **maestría** se añade **+1 Función**.
  - **Reescritura de Estado**
    - Esto no cuenta como función; puede hacer que sus propios movimientos tengan una naturaleza distinta, pudiendo modificar incluso su elemento.
  - **Reescritura de Funciones**
    - Permite cambiar una **propiedad** por otra propiedad distinta que esté al mismo nivel de calidad.
      - Se excluyen:
        - Recuperación Total / Resurrección
        - Golpe Seguro / Defensa Segura
    - Permite cambiar un **efecto adicional** por otro efecto adicional distinto que esté al mismo nivel de calidad.
      - Se excluyen:
        - Sellado / Absoluto
          - Estos cambios gastarán **dos funciones** en vez de una.
  - **Reescritura Anticipada**
    - Puede modificar las **sumas** y **porcentajes** de **objetos**, esto puede hacerlo **sin CD**, y se mantiene **fuera/dentro de combate**.
  - **Fijación de Resultado**
    - Permite que el movimiento del usuario **ignore** las **resistencias e inmunidades** del rival.
  - **Reescritura de Coordenadas**
    - El usuario puede reescribir o intercambiar las coordenadas de uno o varios objetivos al mismo tiempo.
      - **Teletransporte Absoluto**
      - **Intercambio de Posición Absoluto**
- **Naturaleza**
  - **Karma-Mágico:** ???
  - **Elemento:** ???
- **Consumo**
  - **Aguante:** 10.000
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 10 Turnos
    - El **CD** es **Individual** en cada función.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.

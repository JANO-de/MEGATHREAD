# ✮ ⋆ ˚｡ Potenciación (F)

![[9b4ce2da9e297e1bc98c4974edd73ae8.jpg]]

**✦ Potenciación.** Permite incrementar la fuerza del usuario notoriamente. También puede utilizarse en objetivos ajenos al usuario, por ejemplo aliados.

- **Estadísticas**
  - **Suma:** 100 **(F. Principal)** `〨Potenciación〨`
  - **Porcentaje:** 10% **(F. Principal)** `〨Potenciación〨`
- **Propiedades**
  - **Rango:** 3 Zonas
  - **Supremacía** `〨Potenciación〨`
    - Si se alcanza **1.000%** de maestría, se volverá **supremacía absoluta**.
  - **Quiebre** `〨Potenciación〨`
    - Si se alcanza **500%** de maestría, se volverá **quiebre absoluto**.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
    - **Aguante:** 5.000 x Turno
      - Si se intenta utilizar en otros objetivos que no son el propio usuario, **sí** gastará energías.
  - **CD:** 0 Turnos

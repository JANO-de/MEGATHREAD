**Eliminatoria.** El usuario recibe una potenciación en todos sus músculos, la cual le permite varias cosas: entre ellas la capacidad de utilizar **quiebre** a través de **técnicas ajenas**, por ejemplo que utilicen un bastón para lanzar una bola de fuego, que el usuario golpee la bola de fuego provocaría que el bastón reciba el efecto de **quiebre**, **solo aplica a las armas que se hayan utilizado para el uso de la técnica**, esto incluye **equipamiento**, no solo **armamento**. Esta potenciación entrega una gran cantidad de **fuerza física** ya de base, pero por cada **armamento/equipamiento quebrado**, el usuario **recibirá acumulaciones de la misma potenciación**, **también se reciben acumulaciones por cada técnica repetida que use el rival**.

- **Estadísticas**
  - **Fuerza Final:** +10% x Acumulación **(F. Principal)**
  - **Porcentaje:** 50% x Acumulación **(F. Física)** `〨Guerrero〨`
- **Propiedades**
  - **Quiebre Absoluto**
  - **Repulsión Absoluta**
    - Aplica este efecto **únicamente** cuando impacta un ataque contra el objetivo directamente, o contra una técnica que haya utilizado un **armamento/equipamiento**.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 0
  - **Logro:** Conquista de Terrenos

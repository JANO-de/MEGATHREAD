**Alimento de Desgracia.** Cada vez que el objetivo falla una habilidad a causa del efecto de miedo, se le reducen las estadísticas, ignorando inmunidad a esto mismo. Aplica como si fuera una reducción de numero fijo a pesar de ser porcentual.

- **Efectos Adicionales**
  - **Reducción de Estadísticas:** -0,1%`〨Oscuridad〨`

  - **Karma-Mágico:** Potenciación

- **Consumo**

  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

**Doppelganger.** El usuario se divide en una replica de si mismo la cual no comparte cooldown con él. Esta replica tiene duración dependiendo de cuanta maestría tenga el usuario.

- **Efectos Adicionales**
  - **Miedo:** 2 Acciones
- **Propiedades**
  - **Rango:** 2 Zonas
  - **Duración:** 2 Turnos `〨Oscuridad〨`
    - Cada **500%** de **maestría** se añade **+1 turno**.
- **Naturaleza**
  - **Karma-Mágico:** Luz
  - **Elemento:** Oscuridad
- **Consumo**
  - **Aguante:** 2.000
  - **CD:** 5 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Medio.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 2

**Inyección.** Cada vez que el usuario afecte a un objetivo con un efecto de miedo, el afectado perderá una inmunidad a elección del usuario. Cada vez que aplique miedo a alguien, obtendrá el usuario un aumento de estadísticas durante el resto del combate de manera acumulable.

- **Estadísticas**
  - **Porcentaje:** 20% **(General)** `〨Oscuridad〨`
- **Efectos Adicionales**
  - **Inhabilita:** Inmunidad
    - **Limite:** 1 x Acumulación `〨Oscuridad〨`
- **Propiedades**
  - **Supremacía**
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Oscuridad
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Entrenamiento:** Calidad ‘_Media_’.

**Experiencia Traumatizante.** Por cada acción en la que un objetivo esté sufriendo un efecto de miedo o adormecido aplicado por el usuario, recibirá daño mental el afectado.

**Sentencia de Muerte.** Se disparan unos pinchos de tamaño variable los cuales siguen a sus objetivos hasta impactar. Si los objetivos tienen **Adormecido** o **Miedo**, esta habilidad tendrá **Golpe Seguro**.

- **Estadísticas**
  - **Hits Singulares:** 1
    - Por cada acción de **Miedo** o **Adormecido** que haya recibido previamente el objetivo se sumará **+1 Hit Singular**.
  - - **Daño Verdadero/Mental:** 7% **(F. Karma/Velocidad)**
      - **Suma:** 500 **(F. Karma/Velocidad)** `〨Oscuridad〨`
        - Se puede elegir con cual de estas dos estadísticas escala.
- **Efectos Adicionales**
  - **Ejecución**
    - Aplica en todo el cuerpo de golpe.
      - Solo si el objetivo tiene un efecto de **miedo**.
- **Propiedades**
  - **Rango:** 7 Zonas

  - **Ignora:** Counter/Absoluto
  - **Ignora:** I-Frame/Absoluto
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Oscuridad
- **Consumo**
  - **Aguante:** 10.000
  - **CD:** 10 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.

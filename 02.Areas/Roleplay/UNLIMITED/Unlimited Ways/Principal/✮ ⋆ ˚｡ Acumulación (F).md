# ✮ ⋆ ˚｡ Acumulación (F)

![[bc133b2c1672b95fe143ccce1973f6a1.jpg]]

**✦ Acumulación.** Cada vez que se recibe un golpe o daño, se adquiere una “Carga de Acumulación”. Estos puntos de carga se acumulan durante todo el combate y se pueden canjear en cualquier momento del mismo por ciertas ayudas. Solo puedes canjear una cosa por cada punto pero puedes ir acumulando las mismas ayudas. Por cada punto de carga que se tiene canjeado, el usuario irá perdiendo energías constantemente.

- **Estadísticas**
  - **Porcentaje:** 10% x Carga **(General)** `〨Acumulación〨`
- **Propiedades**
  - **Daño Físico:** -0,1% x Carga `〨Acumulación〨`
  - **Daño Tóxico:** -0,1% x Carga `〨Acumulación〨`
  - **Daño Mental:** -0,1% x Carga `〨Acumulación〨`
  - **Daño Espiritual:** -0,1% x Carga `〨Acumulación〨`
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 5.000 x Carga x Turno
  - **CD:** 0 Turnos

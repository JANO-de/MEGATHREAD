# ✮ ⋆ ˚｡ Recolección

![[78b627f88e3b726538c581561a8d51e8.jpg]]

# **¿En que consiste?**

### ﹁ Es un sistema que podemos utilizar para **extraer**. Así adquieres **materiales** que puedes utilizar para **varios fines**, o puedes **venderlos**.

---

# **Requisitos / Pasos**

### ﹁ Se requiere de una **Pala de Botanista**.

### ﹁ Una vez tienes la **Pala de Botanista**. Te diriges a una zona con objetos que se puedan recolectar; por ejemplo un **desierto**, **bosque** o **cueva**.

### ﹁ Estando en la zona correspondiente, tiramos un **1d6**, el resultado de este dado decidirá de que calidad será el material que encontremos. Este paso tiene un **cooldown** de **10 minutos**. Por cada estrella que tenga el material, su dificultad/fuerza de extracción será mayor, añadiéndose este número al resultado de su propio dado.

1. **Una estrella (+0 de Fuerza)**
2. **Dos estrellas (+1 de Fuerza)**
3. **Tres estrellas (+2 de Fuerza)**
4. **Cuatro estrellas (+3 de Fuerza)**
5. **Cinco estrellas (+4 de Fuerza)**
6. **Seis estrellas (+5 de Fuerza)**

### ﹁ Luego, debemos extraerlo, para esto necesitaremos realizar la fuerza adecuada. Para hacer esto, debemos tirar un **1d10** que decidirá el número de la **fuerza/dificultad del material**, y luego otro **1d10** que decidirá **nuestra fuerza**. Si empatamos u obtenemos un número mayor, lo habremos extraído con éxito, de lo contrario se desperdiciará. (**El número máximo es 10 aunque el material sume más fuerza al dado de ese número.**)

### ﹁ Para el paso de extracción, se requiere una narración de calidad ‘**Baja**’.

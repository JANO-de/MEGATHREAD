# ✮ ⋆ ˚｡ Alfa

![[320c0849888dd5ea51ead819f49afee5.jpg]]

**✦ Alfa.** Cuantos más aliados adquiera el usuario, mayor será el poder que este obtendrá. Cuando esta habilidad se encuentra suficientemente progresada, permite adquirir habilidades de sus aliados hasta cierto punto.

- **Estadísticas**
  - **Porcentaje:** 10% x Aliado **(General)** `〨Alfa〨`
- **Propiedades**
  - **Aprendizaje de Aliados:** 0 `〨Alfa〨`
    - Por cada **500%** de maestría en esta habilidad, puedes aprender **+1** habilidad de uno de tus aliados, solo debe enseñártela con intenciones de que la aprendas.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos

  - **Petrificación Absoluta:** 7 Acciones

  - **Maestría Total:** +35% **(Explosión)**

  - **Ignora Inmunidad:** Temperatura
  - **Corta Regeneración**
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.

## ᴛéᴄɴɪᴄᴀꜱ

**Explosión de Supernova.** Una supernova es una explosión devastadora y extremadamente energética que ocurre cuando una estrella muere, liberando una cantidad masiva de energía y material al espacio, siendo en resumen, una explosión de cualidades increíbles. Se vuelve más poderosa cuanta más energía acumuló previamente el usuario.

- **Estadísticas**
  - **Suma:** 250 x Acumulación **(F. Principal)** `〨Artillero〨`
- **Efectos Adicionales**
  - **Destello Absoluto:** 5 Acciones
  - **Cenizas Absoluto:** 5 Acciones
  - **Petrificación Absoluto:** 5 Acciones
- **Propiedades**
  - **Rango:** 5 Zonas
    - **AOE**
  - **Supremacía Absoluta**
  - **Acumulaciones Explosivas**
    - El usuario puede añadir energía adicional a esta técnica a cambio de acumulaciones que incrementarán la potencia de esta misma
      - **Limite:** 1 Acumulación `〨Artillero〨`
        - Cada **200%** de **maestría** se puede añadir **+1 Acumulación**.
  - **Ignora:** Absorción/Absoluta
- **Naturaleza**
  - **Karma-Mágico:** Temperatura
  - **Elemento:** Explosión
- **Consumo**
  - **Aguante:** 5.000 x Acumulación
    - No aplica el **Nivel de Drenaje**.
  - **CD:** 8 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5

**Caja de Pandora.** Una calamidad realmente desastrosa, todas las técnicas que escalen con **explosión** podrán escalar con **artillero** y **viceversa**. Las técnicas ofensivas área tendrán un drenaje disminuido.

- **Propiedades**
  - **Calamidad**
    - Si una habilidad utiliza **maestría** de **artillero**, el usuario puede hacer que utilice **maestría** de **explosión**. También funciona al contrario.
  - **Nivel de Drenaje:** +1 `〨Artillero〨`
    - Esto aplica a todas las técnicas ofensivas que sean **Semi-AOE/AOE** originalmente. Se saltan esto si pertenecen a '**Caja Prehistórica**' o son **explosivas**.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

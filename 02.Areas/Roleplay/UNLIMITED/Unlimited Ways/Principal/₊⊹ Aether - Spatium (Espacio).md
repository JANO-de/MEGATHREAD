## ꜰᴏʀᴍᴀꜱ

**Paso de Ráfaga.** Permite al usuario moverse a gran velocidad, convirtiendo esta velocidad a su vez en su **F. Principal**.

- **Estadísticas**
  - **Suma:** 20.000 **(Velocidad)**
- **Propiedades**
  - **Velocidad → F. Principal**
    - Solo aplica en **técnicas** de **Fuerza**.
- **Naturaleza**
  - **Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
    - No se aplica el **Nivel de Drenaje**.
  - **Vitalidad Máxima:** 50.000 x Turno Propio
    - Se puede recuperar si se descansa luego del combate en algún lugar de reposo.
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Armamento:** Estilo.
    - **Porcentaje:** +50% **(Velocidad)**
      - **Supremacía**
      - **Parálisis:** +50%
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 7

## ᴛéᴄɴɪᴄᴀꜱ

**Mundo en Orbita.** El usuario puede ver el entorno como un espacio en el que puede formar portales, atraer objetivos mediante borrar espacio, o repelerlos mediante añadir espacio. El espacio borrado no dañará a seres vivos u objetos ya que solo aplica al propio entorno y no como tal a la estructura de las cosas. Mientras esta habilidad se encuentre activa el usuario tiene acceso a varias ramas.

- **Estadísticas**
  - **Porcentaje:** 50% **(General)** `〨Mago〨`
- **Efectos Adicionales**
  - **Encarcelamiento Absoluto**
- **Propiedades**
  - **Rango:** 7 Zonas
  - **Duración:** 1 Turno Propio `〨Mago〨`
    - Cada **500%** se aumenta **+1 Turno**.
  - **Teletransporte Absoluto**
    - Pueden teletransportar fuera del rango de esta habilidad.
  - **Atracción / Repulsión**
  - **Maestría Total:** +35% **(Vacío)**
    - **Acceso Elemental:** Vacío
  - **Maestría Total:** +35% **(Gravedad)**
    - **Acceso Elemental:** Gravedad
      - Esta raza puede escalar con cualquiera de estas maestrías.
- **Naturaleza**
  - **Karma-Natural:** Espacio-Temporal/Entorno
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
    - No se aplica el **Nivel de Drenaje**.
  - **Vitalidad Máxima:** 50.000 x Turno Propio
    - Se puede recuperar si se descansa luego del combate en algún lugar de reposo.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 7

**God Step.** Runa que permite moverse a través del espacio en un instante, logrando teletransportación precisa y continua mientras se mantenga el control del aether. Esta habilidad se puede aplicar en técnicas ofensivas si se tiene afinidad con este tipo de aether.

- **Estadísticas**
  - **Suma:** 500 **(Velocidad)** `〨Espadachín〨`
- **Propiedades**
  - **Rango:** Indefinido
  - **Teletransporte Absoluto**
    - Si se tiene afinidad con este aether, los ataques pueden teletransportarse contra su objetivo casi directamente en su cuerpo.
- **Naturaleza**
  - **Karma-Natural:** Espacio-Temporal/Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000
    - No se aplica el **Nivel de Drenaje**.
  - **Vitalidad:** 70.000
    - No se puede regenerar hasta finalizar el combate.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 7

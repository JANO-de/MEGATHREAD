**Dios del Trueno Volador.** Permite colocar marcas sobre cualquier superficie, sean objetos inanimados o seres vivos. Proporciona la capacidad de teletransportarse en un instante a estos objetivos marcados e incluso acompañar este teletransporte con un movimiento (**El teletransporte en si no cuenta como acción**). Las marcas se pueden colocar mediante contacto físico incluso si es utilizando armas (**El karma también, pero únicamente en sólido**), también es posible movilizar las marcas para que se desplacen hasta objetivos diferentes pero se requeriría de una mayor velocidad para funcionar.

- **Estadísticas**
  - **Suma:** 150 **(Velocidad)** `〨Chakra〨`
- **Propiedades**
  - **Rango:** Indefinido
  - **Evasión de Marca**
    - **Evasión Absoluta**
  - **Marca Ofensiva**
    - Cuando te teletransportas a un objetivo marcado para atacarlo tu velocidad será la del **teletransporte**.
      - Una vez utilizada la marca para atacar, la marca desaparecerá.
        - No puedes colocar otra marca durante esta acción ofensiva.
- **Naturaleza**
  - **Karma-Mágico:** Espacio-Temporal
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 3.000
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Puntos de Habilidad:** 3

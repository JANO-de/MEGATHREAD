  - **Aguante:** 4.000

**Mundo de las Tentaciones.** Mundo virtual que permite al usuario afectar directamente la consciencia de los presentes, influenciando el espíritu y mente de los mismos. Dentro de este mundo los presentes perderán energía vital constantemente. Dentro de este mundo solo existe la mente y el espíritu, significando que todos los daños irán dirigidos a esto mismo.

- **Estadísticas**
  - **Daño Mental/Espiritual:** 0,4% x Turno `〨Mago〨`
  - **Porcentaje:** 20% **(General)** `〨Mago〨`
- **Efectos Adicionales**
  - **Encarcelamiento Absoluto**
  - **Control Mental:** 4 `〨Mago〨`
    - Cada vez que se falle la dimensión se sumarán **+4** a esto.
- **Propiedades**
  - **Rango:** 4 Zonas
  - **Duración:** 1 Turno Propio `〨Mago〨`
    - Cada **500%** se aumenta **+1 Turno**.
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000 x Turno
  - **CD:** 7 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Puntos de Habilidad:** 4

**Tiempo de Desesperación.** Materializa el '**Mundo de las Tentaciones**' en una realidad virtual superior. Dentro de este mundo todos los daños afectarán a todo el estado vital al mismo tiempo. Dentro de este mundo el usuario tiene una autoridad mayor, lo que le permite remover y añadir propiedades.

- **Estadísticas**
  - **Daño Estado Vital:** 0,6% x Turno `〨Mago〨`
  - **Porcentaje:** 40% **(General)** `〨Mago〨`
- **Efectos Adicionales**
  - **Encarcelamiento Absoluto**
  - **Control Mental:** 6 `〨Mago〨`
    - Cada vez que se falle la dimensión se sumarán **+6** a esto.
- **Propiedades**
  - **Rango:** 6 Zonas
    - **Multi-Target/Semi-AOE/AOE**
  - **Duración:** 1 Turno Propio `〨Mago〨`
    - Cada **500%** se aumenta **+1 Turno**.
  - **Cambio de Finalidad**
    - El usuario puede cambiar con que estadística escala una técnica propia.
  - **Autoridad Superior**
    - El usuario puede añadir **Propiedades** y **Efectos Adicionales** a sus propias técnicas, aunque limitadamente.
      - Cada turno tiene un limite de cuanto puede añadir de forma general y depende de si la técnica es **ofensiva** o **defensiva** saber cuales puede añadir. Colocarlo **Absoluto** contará como **2**.
      - **Propiedades**
        - Supremacía/Absoluta **(Defensivo/Ofensivo)**
        - Vampirismo **(Ofensivo)**
        - Corta/Inhabilita Regen **(Ofensivo)**
        - Quiebre/Absoluto **(Ofensivo)**
        - Repulsión/Absoluta **(Ofensivo)**
        - Atracción/Absoluta **(Ofensivo)**
        - Stun/Silencio **(Ofensivo)**
        - Absorción/Absoluta **(Defensivo)**
        - Provocación/Inversa **(Defensivo)**
        - Evasión/Absoluta **(Defensivo)**
      - **Efectos Adicionales**
        - Todos los **efectos elementales/generales** se pueden añadir en cualquiera de los dos tipos de técnica.
      - **Cantidad:** 1 Efecto/Propiedad `〨Mago〨`
        - Cada **1.000%** se aumenta **+1 Efecto/Propiedad**.
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 6.000 x Turno
  - **CD:** 9 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Eterno.
  - **Puntos de Habilidad:** 6
  - **Mundo de las Tentaciones**

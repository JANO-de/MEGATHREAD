**Fase de Adquisición.** Permite al usuario sumarse a sus propias estadísticas, la **fuerza**, **resistencia** y **velocidad** de su **vínculo de bestia** sin que esta las pierda. Esto ocurre al mismo también viceversa, y ambos son potenciados. Esto se puede hacer con varias bestias al mismo tiempo siempre y cuando se esté vinculando a ellas. **(Todo eso es sin contar los pasivos.)**

- **Estadísticas**
  - **Porcentaje:** 5% **(General)** `〨Vínculo de Bestia〨`
- **Propiedades**
  - **Combinación de Estadísticas**
    - El **usuario** y sus **vínculos de bestia** se **suman entre si** sus **estadísticas base**.
  - **Recuperación de Aguante:** +500 `〨Vínculo de Bestia〨`
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 1

**Experiencia Igualada.** Cuando una bestia vinculada al usuario, o el propio usuario obtiene experiencia, la otra parte también la recibe, siendo un progreso compartido entre maestro y vinculo. Esto entrega tanto al usuario como a sus vínculos un aumento de progresión. El usuario puede utilizar los aumentos de progresión que tiene por esta pasiva con las bestias domesticadas también, pero no puede compartir progreso con ellas.

- **Propiedades**
  - **Progresión Vinculada**
    - Cuando una bestia vinculada recibe experiencia, el usuario también.
    - Cuando el usuario recibe experiencia, sus vínculos de bestia también.
  - **Experiencia:** +x1
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Media.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 2

[image.png](https://trello.com/c/gobF2LkO)

**Codo con Pata.** Entrega a todos los **vínculos de bestia** del usuario, un aumento en **movimientos**, lo que les permite desarrollar mejor sus movimientos, entregando mayores capacidades en combate al deshacerse de las dudas, y un incremento en las **acciones**.

- **Estadísticas**
  - **Porcentaje:** 15% **(General)** `〨Vínculo de Bestia〨`
    - Aplica para los **vínculos de bestia** y **usuario**.
- **Propiedades**
  - **Acción Adicional:** 3 `〨Vínculo de Bestia〨`
    - Solo para los **vínculos de bestia**.
      - Cada **300%** de **maestría** se añade **+1 Acción**.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 3

**Fase de Integración.** Permite al usuario entrar en la segunda fase del vínculo de bestia **(Manteniendo las ventajas de la primera.)**. Para empezar, en esta versión, el usuario puede llegar a realizar lo que innatamente su bestia tiene. Esto significa que es capaz de tener las **pasivas** de su **vínculo de bestia**. Pero esta fase solo puede usarla con **una bestia a la vez**. Estética y narrativamente, en esta fase es posible que el usuario tenga características físicas de la bestia.

- **Estadísticas**
  - **Porcentaje:** 20% **(General)** `〨Vínculo de Bestia〨`
- **Propiedades**
  - **Detección:** 4 `〨Vínculo de Bestia〨`
  - **Predicción:** 4 `〨Vínculo de Bestia〨`
  - **Pasivas Compartidas**
    - Tanto el **usuario** como la **bestia** con la que está utilizando esta fase, **comparten pasivas** entre ellos.
  - **Supremacía**
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000 x Turno
  - **CD:** 0 Turnos
  - **Activado:** Fase de Adquisición
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 4

**Deviant.** Los Deviants engloban todo lo que se conoce como _combinaciones elementales_ y _evoluciones elementales_ e incluso _elementos únicos_. Esta habilidad entrega acceso al usuario de utilizar más **evoluciones elementales** de las que normalmente se pueden adquirir **(Para utilizar esta habilidad, se requiere tener la Fase de Integración activa o más.).**

- **Propiedades**
  - **Deviant**
    - Cuando el usuario tiene un **Slot de Deviant**, puede elegir evolucionar temporalmente uno de sus **elementos principales**, adquiriendo la **evolución elemental** de uno de estos, pudiendo utilizar todas las habilidades de su rama, mientras su rango se lo permita. **(Para tener la habilidad oculta se sigue necesitando adquirir el logro.)**
      - El usuario puede entrenar estos elementos siempre y cuando tenga el modo activo, el progreso de las distintas maestrías se le guardará.
        - **Si durante un combate se está utilizando un slot, ese slot no puede cambiarse hasta finalizar el combate.**
        - **Solo se aceptan evoluciones/combinaciones de elementos que ya tenga el usuario.**
  - **Slot de Deviant:** 1 `〨Vínculo de Bestia〨`
    - Cada **1.000%** de **maestría** se adquiere **+1**.
      - Por cada slot de **Deviant** que tenga el usuario, podrá colocarse una **Afinidad Elemental** nueva en su ficha, pero estas no lo ayudarán a entrenar los elementos a no ser que tenga los modos activos.
        - Los **Deviants**, al solo poder usarse con estas fases activas, no son algo que el usuario pueda utilizar de base.
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
  - **Activado:** Fase de Integración
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Entrenamiento:** Calidad ‘_Alta_’.
  - **Puntos de Habilidad:** 5

**Conexión Única.** Esto es un añadido a la _Fase de Integración_ y las demás fases. Permite que estas fases se puedan utilizar con más de un vínculo al mismo tiempo, y adicionalmente, que el usuario ya no solo comparta pasivas con quienes está utilizando sus fases, si no también las otras habilidades. **(No comparte maestrías.)**

- **Propiedades**
  - **Habilidades Compartidas**
    - Tanto el **usuario** como la **bestia** con la que está utilizando esta fase, **comparten** **técnicas** entre ellos.
  - **Slots de Vínculo:** 1 `〨Vínculo de Bestia〨`
    - Cada **1.000%** de **maestría** se adquiere **+1**.
      - Estos slots son de con cuantos vínculos se puede estar utilizando la **Fase de Integración o más** al mismo tiempo.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Eterno.

**Realmheart.** El usuario activa una fase muy especial, apareciendo marcas de runas por todo su cuerpo de pies a cabeza con una tonalidad especial. En esta fase los ojos del usuario cambian de intensidad, y todos los sentidos del usuario se vuelven capaces de detectar el karma de los elementos, esto incluye el karma **natural** y **mágico**, lo que le entrega un mayor refinamiento en su uso elemental, no solo gastando menos energías al usar elementos, si no que pudiendo utilizar **karma natural** en estos mismos. **(En este estado el usuario SÍ comparte las maestrías con sus vínculos.)**

- **Estadísticas**
  - **Porcentaje:** 50% **(General)** `〨Vínculo de Bestia〨`
- **Propiedades**
  - **Maestría Total:** +50%
    - Aplica para todos los elementos a la vez.
  - **Visión de Partículas**
    - Las partículas de karma natural elemental se encuentran en todos lados, pero solo las de elementos principales.
      - Para usar partículas de evoluciones, se debe usar deviant en estas partículas.
      - para usar las de combinados se deben juntar partículas de los elementos correspondientes.
        - El usuario solo puede ver/interactuar con partículas de los elementos que posee, incluyendo el deviant.
  - **Interacción de Partículas**
    - Cuando el usuario utiliza un elemento mediante la interacción de partículas elementales del entorno.
      - El elemento será de **Karma Natural** en vez de **Mágico**.
        - Se puede convertir en **mágico** si el usuario utiliza su **núcleo de karma mágico** para ello.
      - **Nivel de Drenaje:** +100%
        - Se contará como que el usuario tiene el **doble** de **Nivel de Drenaje**.
          - Solo aplica en **elementos** que se utilicen con este método.
- **Naturaleza**
  - **Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
    - No aplica el **Nivel de Drenaje**.
  - **CD:** 0 Turnos
  - **Activado:** Fase de Integración
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Entrenamiento:** Calidad ‘_God_’.
  - **Puntos de Habilidad:** 7

**Realmheart Desatado.** Esto actúa como un “simple” power-up de lo que es el propio vínculo. Este estado es increíblemente peligroso para el usuario, porque aunque le entrega un aumento muy notorio en sus capacidades, esto es a costa de su estado vital completamente.

- **Estadísticas**
  - **Suma:** 20.000 **(General)**
  - **Porcentaje:** 50% **(General)** `〨Vínculo de Bestia〨`
- **Propiedades**
  - **Duración:** Combate Completo
  - **Supremacía Absoluta**
  - **Detección:** 7 `〨Vínculo de Bestia〨`
  - **Predicción/Absoluta:** 7 `〨Vínculo de Bestia〨`
  - **Maestría Total:** +150%
    - Aplica para todos los elementos a la vez.
  - **Recuperación de Aguante:** 5.000 `〨Vínculo de Bestia〨`
  - **Slot de Deviant:** 4 `〨Vínculo de Bestia〨`
    - Cada **1.000%** de **maestría** se adquiere **+1**.
      - El usuario puede utilizar cualquier **elemento principal** y los **deviants relacionados a estos**.
- **Naturaleza**
  - **Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
    - **Retroceso Absoluto:** 100%
      - El usuario morirá, perdiendo todas sus propias vidas adicionales y **Núcleo Mágico**. Incluso si llega a sobrevivir de alguna manera, el usuario seguirá perdiendo su núcleo en el acto.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 0
  - **Logro:** You’re not Going to Make It

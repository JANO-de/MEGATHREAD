## ᴘᴀꜱɪᴠᴀꜱ

**Sangre Saiyan.** Pueden controlar fácilmente sus energías, lo que les permite tener mayores capacidades pasivamente en sus cuerpos. Tienen maestrías dignas de una raza guerrera. Además, progresan rápidamente al pelear.

- **Propiedades**
  - **Maestría Total:** +20% **(Esp. Principales)**
  - **Maestría Total:** +20% **(Esp. Evolucionadas)**
  - **Maestría Total:** +20% **(Sellador)**
  - **Maestría Total:** +20% **(Tanque)**
  - **Inmunidad:** Temperatura
  - **Nivel de Drenaje:** +5
  - **Recuperación de Aguante:** 4.000 x Turno `〨Oni〨`
  - **Peleador Innato**
    - Todas las técnicas de esta raza se contarán como si pudieran utilizar la **vía de Propagación** en caso de tenerla.
  - **Raza Guerrera**
    - **Experiencia/Puntos de Habilidad (B.R):** +200%
      - Por cada **B.R** que realicen, se les añadirá un **+20%** a ese potenciador de experiencia.
    - **B.R**
      - Cada **3 Mensajes Propios** en un **B.R** el usuario adquiere una serie de beneficios.
        - **Maestría Total:** +2%
          - Se reparte entre maestrías a elección del usuario.
          - Se debe hacer **calidad ‘Alta’.**
        - **Maestría:** +20%
          - Se reparte entre maestrías a elección del usuario.
          - Se deben respetar los requisitos de **calidad** para obtener **maestría**.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

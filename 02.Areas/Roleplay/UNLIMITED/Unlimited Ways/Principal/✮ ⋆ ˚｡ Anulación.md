# ✮ ⋆ ˚｡ Anulación

![[image_(7) (1).png]]

**✦ Anulación.** Esta es una habilidad que permite anular otras habilidades primordiales a cambio de habilidades primordiales del mismo grado. Se puede anular una habilidad primordial una vez de forma gratuita pero debe ser de **tercer grado o menos**.

- **Efectos Adicionales**
  - **Bloqueo de Habilidad**
    - No podrán utilidad habilidades primordiales anuladas por esta habilidad. Se debe dar una habilidad primordial propia del mismo grado o más para anular habilidades ajenas.
      - **Anulación:** 1 `〨Anulación〨`
        - Por cada **1.000%** de **maestría**, cada habilidad propia que te anules servirá para anular **una más** del oponente.
- **Propiedades**
  - **Rango:** 1 Categoría
    - Si salen del rango de esta habilidad, dejarán de tener las habilidades anuladas, aunque las habilidades que tú diste a cambio de anular esas, las recuperarás.
- **Naturaleza**
  - **Anti-Magia:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000
  - **CD:** 0 Turnos

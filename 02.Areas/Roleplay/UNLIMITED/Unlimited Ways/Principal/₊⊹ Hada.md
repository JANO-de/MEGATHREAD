  - **Regeneración de Estado Vital:** 10.000 x Turno `〨Mago〨`
  - **Recuperación de Aguante:** 10.000 x Turno `〨Mago〨`

    - Las habilidades del usuario pueden afectar también al alma.

## ᴛéᴄɴɪᴄᴀꜱ

**Small World.** El usuario crea una dimensión cerrada completamente aislada del entorno real. Dentro de este espacio, controla las leyes físicas y mágicas, pudiendo alterar la gravedad, el tiempo o las condiciones vitales. Ningún ataque externo puede penetrar este mundo, convirtiéndolo en un dominio perfecto para sellar enemigos o proteger aliados.

- **Estadísticas**
  - **Suma:** 250 **(Velocidad)** `〨Mago〨`
- **Efectos Adicionales**
  - **Control Concreto**
    - Se puede afectar a objetivos sin **CD** que estén dentro del laberinto aunque se necesita la suficiente velocidad.
      - **Presión Absoluta:** 5 Acciones
      - **Repulsión**
      - **Atracción**
- **Propiedades**
  - **Limite:** 1 Piso del Laberinto `〨Mago〨`
    - Cada **500%** de **maestría** se puede añadir **+1 Piso**.
      - Cada piso se cuenta como una **dimensión** diferente, lo que implica que para ir de un piso a otro, hay que pasar por cada zona en orden gastando acciones para ello.
        - Da igual que una técnica ocupe varias zonas de área, porque solo alcanzará un piso.
  - **Encarcelamiento Absoluto**
  - **Entrada/Salida**
    - Este laberinto solo puede tener **una** forma de **entrar/salir** tanto por dentro como por fuera.
  - **Resurrección**
    - Cada vez que el usuario o un aliado fallece **dentro** de un piso de este laberinto, puede ser resucitado al momento.
      - **CD:** 10 Turnos
        - Este **CD** es individual para cada objetivo.
- **Naturaleza**
  - **Karma-Mágico:** Espacio-Temporal/Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5

- **Propiedades**
  - **Limite**

  - **Sellado Absoluto**
    - Puede convertir en un bucle espacial cualquier piso del laberinto indefinidamente para extender el piso en cuestión constantemente para que los presentes en el mismo no puedan retirarse.
- **Naturaleza**
  - **Karma-Natural:** Espacio-Temporal/Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 10 Turnos
  - **Ciclo de Reencarnación**
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 7

## ᴘᴀꜱɪᴠᴀꜱ

**Hija del Renacimiento.** Tiene afinidad con todos los elementos naturalmente, además de tener ciertos beneficios pasivamente.

- **Propiedades**
  - **Maestría Total:** +20% **(Elementos)**
  - **Maestría Total:** +20% **(Paladín)**
  - **Maestría Total:** +20% **(Trampista)**
  - **Maestría Total:** +20% **(Mago)**
  - **Maestría Total:** +20% **(Brujo)**
  - **Maestría Total:** +20% **(Sellador)**
  - **Maestría Total:** +20% **(Investigador)**
  - **Maestría Total:** +20% **(Mecánico)**
  - **Maestría Total:** +20% **(Clérigo)**
  - **Maestría Total:** +20% **(Tameador)**
  - **Maestría Total:** +20% **(Alquimista)**
  - **Maestría Total:** +20% **(Cocinero)**
  - **Maestría Total:** +20% **(Subrama)**
    - Puede elegir **UNA** subrama a la cual aplicarle esta maestría.
  - **Aumentos Pasivos**
    - **Aguante:** +x1 **(Pasivo)**
  - **Recuperación de Aguante:** 4.000 x Turno `〨Mago〨`
  - **Nivel de Drenaje:** +5
  - **Ciclo de Reencarnación**
    - Es capaz de reencarnar con sus recuerdos y mismas habilidades cada vez que muere por completo. **(Tras perder todas las vidas extra. Que ignoren vidas extra no significa que no podrás reencarnar)**
    - Es necesario tener activa la forma '**Ciclo de Reencarnación**' para usar esta pasiva.
      - Pero esto lo devuelve al **Rango Bajo** nuevamente, si muere antes de recuperar al menos **Rango Estelar**, fallecerá del todo.
        - No será necesario volver a gastar puntos en sus habilidades, pero solo podrá usarlas cuando alcanza el rango correspondiente de cada una.
        - Para los distintos rangos y demás sí debe volver a utilizar los **Puntos**, así como para sus **Niveles** ya sea de **Drenaje** u otro tipo de estadística.
          - Las **maestrías** entrenadas se mantienen.
          - Los **objetos** se mantienen.
          - Las **habilidades karma** se mantienen.
      - Cada uso de esta pasiva dará permanentemente una acumulación de '**Reencarnación**'.
        - Cuando reencarnas, puedes subir de nuevo hasta el rango en el que estabas saltándote el CD de subida de rangos.
          - Cada **dos reencarnaciones completas** el usuario podrá adquirir una **habilidad karma adicional**.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

# _**Odio**_

## ꜰᴏʀᴍᴀꜱ

**Animosity.** El usuario manifiesta su hostilidad, tiñendo su alma de negro temporalmente. Una vez se entra en este estado no se detiene hasta finalizar el combate. Cuanto más tiempo se la pase el usuario en este estado más se incrementarán sus capacidades pero al mismo tiempo más daños recibirá.

- **Estadísticas**
  - **Porcentaje:** 50% x Turno **(General)** `〨Karma〨`
- **Efectos Adicionales**
  - **Efectos Negativos:** +7 Acciones **(Ruta Genocida)**
  - **Efectos Positivos:** +7 Acciones **(Ruta Pacifista)**
- **Propiedades**
  - **Recuperación de Aguante:** 5.000 x Turno `〨Karma〨`
  - **Recuperación Total/Resurrección**
  - **Supremacía Absoluta**
  - **Acción Adicional:** +1
  - **Maestría Total:** +25% x Turno **(???)**
    - Aplica en **todas** las **maestrías** del usuario.
  - **Maestría Total:** +25% x Turno **(Karma)**
  - **Penetración:** 5% `〨Karma〨`
    - Lo sobrante se volverá **daño crítico**.
- **Naturaleza**
  - **Físico/Karma-Mágico/Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
    - **Estado Vital Máximo:** 50.000 x Turno Propio
      - Se puede recuperar si se descansa luego del combate en algún lugar de reposo.
        - Puedes **elegir** cual **estado vital** te quita, pero **NO** puedes ir alternándolos durante el combate.
  - **CD:** 1 x Combate
    - No se puede desactivar hasta finalizar el combate.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5

## ᴛéᴄɴɪᴄᴀꜱ

**Manifestación de Odio.** Esto es una potenciación de los ataques propios. Estos ataques serán cubiertos por el odio del usuario, cuando estos ataques alcanzan a dañar a un objetivo aplicarán internamente en el afectado constantemente este odio, provocando daños internos constantemente.

- **Estadísticas**
  - **Daño Tóxico:** 6% x Turno **(???)**
    - **Suma:** 300 **(???)** `〨Karma〨`
      - Aplica en la estadística que prefiera el usuario.
        - Estos daños pueden incluso ocurrir varias veces dentro del mismo turno si se impactan varios golpes con esta potenciación.
- **Efectos Adicionales**
  - **Corrupción Absoluta:** 6 Acciones
  - **Raíces Absoluta:** 6 Acciones
- **Propiedades**
  - **Rango:** 6 Zonas
    - **AOE**
- **Naturaleza**
  - **Físico/Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 6.000 x Acción
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Eterno.
  - **Puntos de Habilidad:** 6

## ᴘᴀꜱɪᴠᴀꜱ

**Odio Total.** Si el usuario fallece durante su ultima vida utilizando ‘**Animosity**'. Su cuerpo será completamente consumido por el odio, convirtiéndolo en una entidad completamente formada por el mismo. Esta entidad ya no será el usuario, y es casi imposible que se pueda aprovechar esto para volver a la vida después, pero esta entidad se encargará de erradicar a todos los que te causaron problemas utilizando tu rencor. Esta entidad tendrá su poder a partir de cuando falleciste utilizando '**Animosity**’ e incluso seguirá en aumento aunque sin causarle daños internos a esta misma.

- **Propiedades**
  - **Reencarnación de Rencor**
    - Una entidad sin raciocinio que actúa como la representación del rencor del usuario.
      - Solo se forma si el usuario ya había muerto de manera definitiva. (**Ya no le quedaban más vidas.**)
      - Mantendrá todas las acumulaciones de '**Animosity**'.
        - Podrá seguir utilizando activamente '**Animosity**' para seguir acumulando poder en cada turno de combate de forma permanente, no pierde estado vital con ese estado.
        - Esta criatura tiene el **doble** de **estado vital** que el usuario original.
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0
  - **Animosity**
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

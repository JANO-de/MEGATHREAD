**Revestimiento de Maná.** Esto es una capa de karma la cual protege al usuario considerablemente de posibles impactos. Impidiendo incluso que haya contacto directo con el usuario tan fácilmente. Incluso los efectos elementales durarán menos tiempo en el usuario de lo que deberían.

- **Estadísticas**
  - **Porcentaje:** 15% **(Resistencia)** `〨Maná〨`
- **Propiedades**
  - **Efectos Elementales:** -1 Acción `〨Maná〨`
    - Cada **200%** se restan **1 Acción adicionalmente**.
  - **Vuelo**
    - El usuario puede mantenerse en el aire mientras tenga esta habilidad activa.
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 3.000 x Turno
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 3

**Resonancia de Maná.** El usuario es capaz de vincular su karma con el de sus aliados con la finalidad de recibir apoyo de estos, solo sirven aliados reales, no invocaciones/bestias o similar. Cuantos más aliados haya, mayor será la capacidad del usuario durante sus propias técnicas.

- **Estadísticas**
  - **Porcentaje:** 30% x Aliado Vinculado **(General)** `〨Maná〨`
- **Propiedades**
  - **Maestría Total:** +30% x Aliado Vinculado
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 5.000 x Turno x Aliado Vinculado
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Entrenamiento:** Calidad ‘_Alta_’.
  - **Puntos de Habilidad:** 5

**Zona de Maná.** Esto es un territorio especial en el cual el usuario es capaz de potenciar sus capacidad muy notoriamente en caso de expandirlo por completo. Aunque no puedas expandirlo por completo tras un choque de territorios, puedes seguir manteniéndolo mínimamente para mantener el efecto de '**Defensa Segura**'.

- **Propiedades**
  - **Rango:** 1 Categoría
  - **Maestría Total:** +500%
    - Aplica a todas las maestrías que estén relacionadas con las habilidades que están vinculadas a tu zona de maná.
  - **Zona de Maná**
    - Esta zona de maná puede basarse en hasta **una habilidad** del usuario.
      - No cuentan las habilidades default que pueda tener tu zona de maná en caso de provenir de un clan, como por ejemplo **Hirai**.
  - **Golpe Seguro**
  - **Recuperación de Aguante:** 10.000 `〨Maná〨`
  - **Predicción:** 7 `〨Maná〨`
    - **Predicción Absoluta:** 4 `〨Maná〨`
- **Naturaleza**
  - **Karma-Mágico:** Entorno/Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0 x Turno
    - **Máximo:** 6 Turnos
  - **CD:** 1 x Combate `〨Maná〨`
    - Cada **1.000%** de **maestría** puedes usar **+1 Zona de Maná** a lo largo del combate.
      - **Repercusiones** (**Descansar en un lugar de reposo te sanará.**)
        - Cuantas más veces utilices esta habilidad a lo largo del combate, mayores daños acumularás. Estos daños se van acumulando a partir del segundo uso.
          - **Estado Vital Máximo:** -20% x Uso
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Entrenamiento:** Calidad ‘_God_’.
  - **Puntos de Habilidad:** 7

# **Choque de Territorios**

### Cuando dos o más territorios chocan entre si, se decide al ganador mediante comparar quien tiene una mayor **maestría**. En caso de tener la misma los dominios se contrarrestarán entre si, impidiendo que puedan expandirse.

### Las Zonas de Maná cuentan como **territorios abiertos** a no ser que la propia habilidad de esta misma se relacione con encerrar. Todo dominio puede chocar entre sí, pero aunque un Dominio Abierto pierda el choque, normalmente puede intentar romper desde fuera dominios ajenos, pues externamente al dominio cerrado, el abierto seguirá estando.

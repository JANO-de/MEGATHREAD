## ᴘᴀꜱɪᴠᴀꜱ

**Truth.** El usuario adquiere acceso a un plano… diferente. Dentro de este plano siempre se encuentra “**Truth**“ un sujeto el cual ofrece al usuario establecer acuerdos de verdadera alquimia.

- **Propiedades**
  - **Intercambios de Alquimia**
    - **Métodos de Obtención**
      - En cada '**Rango de Ascensión**' adquieres un intercambio.
      - Cada vez que **mates** a un **jugador**.
      - Cada vez que **mates** a un **jefe**.
        - Debe tener como mucho un rango menos que tú.
    - **Usos**
      - El usuario puede utilizar estos intercambios para cambiar objetos que sean originarios de la misma calidad y tipo.
      - Puede utilizarse a su vez para adquirir aumentos de poder de algún tipo a cambio de otras cosas, o adquirir habilidades nuevas a cambio de las que ya poseías.
        - No se pueden entregar varias cosas a cambio de una a no ser que lo que quieras es entregar un grupo de cosas entero, como una rama elemental, una especialidad, etc…
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

## ᴛéᴄɴɪᴄᴀꜱ

**Hechicería de Proyección.** El usuario se mueve a una velocidad absurda con la intención de tocar a su objetivo, una vez tocado el objetivo se verá paralizado dentro de una pantalla 2D. Si el afectado es golpeado durante esta parálisis recibirá daños mayores a los habituales. **(Se puede aplicar junto a otras técnicas potenciado el cuerpo del usuario.)**

- **Estadísticas**
  - **Suma:** 150/200/250/300/500 **(Velocidad)** `〨Hechicería〨`
    - El **150** sería en rango **superior**, por cada rango se va incrementando.
- **Efectos Adicionales**
  - **Contusión Absoluta:** 3 Acciones
  - **Estasis:** 1 Acción
    - No se puede utilizar este efecto mientras esté colocado.
      - Si se utiliza este efecto durante otras técnicas de cualquier tipo de parálisis funcionará incluso saltándose el límite de parálisis del usuario.
        - **Ignora:** Inmunidad Estasis
  - **Penetración:** 3% `〨Hechicería〨`
    - No hay limite de penetración, la sobrante se volverá daño crítico.
      - La '**Penetración**' final se **doblará**.
- **Propiedades**
  - **Rango:** Contacto Físico
  - **Maestría Total:** +15% **(Proyección)**
- **Naturaleza**
  - **Karma-Mágico:** Sólido/Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 3.000
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Puntos de Habilidad:** 3

**Expansión de Dominio: Time Cell Moon Palace.** Se genera un espacio oscuro, vacío salvo por partículas flotando. Dentro, hay un camino de carne que conduce hacia un ojo gigante, y el usuario se interpone entre el objetivo y dicho ojo. Dentro de este dominio todos los que utilicen movimientos relacionados a la velocidad recibirán daños severos, además cuando el usuario intente atacar a alguien, todos los objetivos a los que esté atacando recibirán estasis durante el ataque. Además los fotogramas del usuario se doblan.

- **Estadísticas**
  - **Daño Verdadero:** 7% **(Velocidad)**
    - **Suma:** 500 **(Velocidad)** `〨Hechicería〨`
      - Este daño será recibido por aquellos que traten de utilizar movimientos basados en velocidad.
- **Efectos Adicionales**
  - **Encarcelamiento Absoluto:** Dominio Completo
  - **Estasis**
    - Durante los movimientos del usuario.
      - Aplica en todos los que estén siendo objetivos de estos movimientos.
- **Propiedades**
  - **Rango:** 3 Zonas
  - **Maestría Total:** +400%
    - Aplica a todas las maestrías que estén relacionadas con las habilidades que están vinculadas a tu dominio.
  - **Dominio Completo**
    - **Elevación de Fotogramas**
      - Los aumentos por cada nivel de subida de fotogramas afectarán el **doble** al usuario.
  - **Golpe Seguro**
- **Naturaleza**
  - **Karma-Mágico:** Entorno/Potenciación
  - **Elemento:** Ninguno
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Expansión de Dominio**
  - **Puntos de Habilidad:** 7

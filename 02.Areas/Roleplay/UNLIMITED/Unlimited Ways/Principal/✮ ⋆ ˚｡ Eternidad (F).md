# ✮ ⋆ ˚｡ Eternidad (F)

![[image_(2).png]]

**✦ Eternidad.** Habilidad que ya no solo actúa como una manifestación, si no como una parte del usuario. Aporta juventud eterna, puede infectarse por condiciones externas, pero el usuario no notará la diferencia ya que tiene inmunidad a condiciones externas comunes, y sobre todo altas capacidades regenerativas ante todo tipo de daño. Sin importar la gravedad de los daños, el usuario no morirá, pero es cierto que sus heridas pueden aun así obstaculizar su ritmo de combate, especialmente perder extremidades.

- **Propiedades**
  - **Inmortalidad**
    - Impide que el usuario de esta habilidad fallezca.
  - **Regeneración:** 40.000 (**Tier III**) `〨Eternidad〨`
    - Aplica a; **Vitalidad**, **Toxicidad**, **Cordura** y **Alma**.
      - **Ignora:** Corta/Inhabilita Regeneración
  - **Inmunidad:** Condiciones Externas
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos

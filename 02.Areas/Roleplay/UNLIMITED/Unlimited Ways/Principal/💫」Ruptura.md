**Ascendencia Cuadrivalente.** Permite al usuario aplicar en su objetivo un efecto de fisura por cada cierta cantidad de golpes directamente impactados, no necesariamente seguidos durante un combate.

- **Efectos Adicionales**
  - **Fisura:** 1 Acción `〨Ruptura〨`
    - Por cada **300%** de **maestría** se le incrementa **+1** la duración.
- **Propiedades**
  - **Requisito**
    - **Hits:** 50 `〨Ruptura〨`
      - Cada **100%** de **maestría** se le resta **-1** a los **hits necesarios**.
        - Hasta que eventualmente solo necesite uno para que el efecto se aplique cada vez.
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ruptura
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 1

**Maestro en Fisuras.** Las habilidades que sean **varios hits**, ya sean **hits singulares** o **normales**, se aumentará la cantidad final de estos mismos.

- **Propiedades**

  - **Hits Normales:** +100%

  - **Karma-Mágico:** Potenciación

**Efímera Eternidad.** Se lanzan una gran cantidad de cortes en contra de todos los objetivos presentes. Cuando esta técnica derrota a un objetivo, todos los cortes sobrantes pueden ir a partir del próximo turno propio a por otro objetivo.

- **Estadísticas**
  - **Daño Verdadero:** 3% **(Velocidad)**
    - **Suma:** 150 **(Velocidad)** `〨Ruptura〨`
      - Se añade **+3%** por cada **objetivo que haya en la zona**.
        - Si tienen **electrificación** a ese **“+3%”** se añadirá otro **“+1%”**.
          - Si tienen **Ruptura** el **daño final** de esta técnica se **doblará**.
- **Efectos Adicionales**
  - **Electrificación:** 3 Acciones
- **Propiedades**
  - **Rango:** 3 Zonas
    - **Multi-Target**
  - **Supremacía**
- **Naturaleza**
  - **Karma-Mágico:** Electricidad
  - **Elemento:** Ruptura
- **Consumo**
  - **Aguante:** 3.000 x Hit
  - **CD:** 6 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 3

**Destello de Octobolto.** Se forman una serie de replicas del propio usuario las cuales duran un solo turno, pero lo bueno de estas copias, es que no comparten cooldown entre ellas, cada una cuenta como una acción adicional la cual se puede saltar el limite original del usuario.

- **Efectos Adicionales**
  - **Electrificación:** 4 Acciones
- **Propiedades**
  - **Rango:** 4 Zonas
  - **Limite de Replicas:** 1 `〨Ruptura〨`
    - Por cada **400%** de **maestría** se incrementa el limite en **+1**.
      - **Acción Adicional:** 1 x Replica
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ruptura
- **Consumo**
  - **Aguante:** 4.000
  - **CD:** 7 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 4

**Presagio Maligno.** Este es un estado especial en el que se manifiesta sobre el usuario un ojo electrizante el cual, por cada que vez que el usuario lance una acción ofensiva, el ojo recibirá una acumulación. Por cada acumulación, al final de ese turno se lanzarán una serie de descargas eléctricas en todo a su alcance.

- **Estadísticas**
  - **Porcentaje:** 30% **(Velocidad)** `〨Ruptura〨`
- **Efectos Adicionales**
  - **Electrificación:** 5 Acciones
- **Propiedades**
  - **Presagio Maligno**
    - **Requisito:** Lanzar una acción ofensiva.
      - **Suma:** 250 **(F. Karma)** `〨Ruptura〨`
        - **Rango:** 5 Zonas
          - **AOE**
        - **Supremacía**
        - **Hits:** 1 x Acumulación
- **Naturaleza**
  - **Karma-Mágico:** Electricidad/Potenciación
  - **Elemento:** Ruptura
- **Consumo**
  - **Aguante:** 5.000 x Turno
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Entrenamiento:** Calidad ‘_Alta_’.
  - **Puntos de Habilidad:** 5

**Tambores de la Eternidad.** Se materializan unos tambores de tomoe eléctricos cerca del usuario. Cada vez que el usuario utilice una técnica multi-hit, su velocidad se incrementará durante el resto del combate de manera acumulable. A su vez, estos tambores disminuyen el cooldown de las evasiones que estén en enfriamiento en ese momento para recuperarlas antes.

- **Estadísticas**
  - **Porcentaje:** 40% x Multi-Hit **(Velocidad)** `〨Ruptura〨`
- **Propiedades**
  - **Cooldown de Evasión:** -6 Acciones x Multi-Hit
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ruptura
- **Consumo**
  - **Aguante:** 6.000 x Turno
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Eterno.
  - **Entrenamiento:** Calidad ‘_Alta_’.

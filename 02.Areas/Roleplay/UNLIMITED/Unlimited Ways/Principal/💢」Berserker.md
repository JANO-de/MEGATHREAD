**Postura Inquebrantable.** Cualquier armamento o equipamiento que tenga equipado el usuario en el momento no podrá ser destruido, ni alterado de forma de alguna manera en contra de la voluntad del portador. Además, las defensas del usuario se muestran siempre mejoradas.

- **Estadísticas**
  - **Resistencia Final:** +5% x Acumulación
    - Se aumenta cada vez que el usuario defiende o cubre un ataque.
- **Propiedades**
  - **Ignora:** Quiebre/Absoluto
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 1

**Gritos de Guerra.** Cuando el usuario recibe un debuff, este es invertido, convirtiéndose en un buff (**Por ejemplo que en vez de bajarle stats, le suban.**). Si algún objetivo enemigo utiliza algo que le entrega buffs, estos serán arrebatados por el usuario.

- **Efectos Adicionales**
  - **Robo de Buffs**
    - Solo aplica en aquellos debuff que sean númericos.
      - Por ejemplo, reducciones de estadísticas, que le suban cooldowns, que le reduzcan detección. Fuera de eso no aplica.
- **Propiedades**
  - **Rango:** 2 Zonas
  - **Debuff → Buffs**
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Medio.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 2

[image.png](https://trello.com/c/JpMDPoed)

**Furia Marcada.** Entrega cierta **resistencia** a cualquier habilidad que **paralice** al usuario, al igual que el usuario **no** necesitará **lanzar dados** para **moverse** durante **efectos similares** a **electrificación**. Tampoco puede ser **forzado** a **cambiar de objetivo**, lo que implica que habilidades de **provocación** no afectan al usuario, al igual que tampoco efectos como por ejemplo el **destello**.

- **Propiedades**
  - **Resistencia de Parálisis:** 1 Turno
    - Durante el primer turno en el que se aplique cualquier tipo de parálisis, el usuario aun podrá moverse libremente.
  - **Inmunidad:** Provocación/Inversa
  - **Muralla Indestructible**
    - Si el usuario tiene las especialidades **Tanque** y **Berserker** ambas con **1.000%** de **maestría** y sus **ocho habilidades**, adquirirán el siguiente beneficio:
      - El **2%** de la **Resistencia Final** del usuario se cuenta para restarse contra **Daño Verdadero**.
        - Esto no aplica contra penetración.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 3

**Sentimiento de Venganza.** Liberando un gas, gritando, emitiendo temblores o liberando una gran oscuridad. El usuario aplica todos los efectos negativos que hayan ocurrido durante el combate, incluyendo los elementales, y los aplica en contra de todos los objetivos alcanzados con las mismas duraciones. Por cada objetivo que haya sido alcanzado por la habilidad, el usuario recibe un aumento de fuerza durante el resto del combate.

- **Estadísticas**
  - **Suma:** 200 **(Velocidad)**
    - **Porcentaje:** 20% x Enemigo **(F. Principal)** `〨Berserker〨`
    - **Fuerza Final:** +20% x Enemigo **(F. Principal)**
- **Efectos Adicionales**
  - **Efectos Negativos**
    - Ocurridos durante cualquier momento del combate.
- **Propiedades**
  - **Rango:** 4 Zonas
    - **AOE**
- **Naturaleza**
  - **Físico:** Gas/Sonido/Vibración/Luz
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000
  - **CD:** 7 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 4

**Armadura Berserker.** Armadura que actúa como muleta para el usuario, al mismo tiempo que como un gran poder que conlleva a consecuencias.

- **Estadísticas**
  - **Porcentaje:** 50% **(F. Principal)** `〨Berserker〨`
- **Propiedades**
  - **Combo de Equipamiento**
    - Permite combinar esta armadura con otra distinta.
      - **Límite:** 1
  - **Dolor Nulificado**
    - No sentirá dolor el portador.
    - Los venenos no mostrarán efectos claros hasta que el combate finalice.
    - **Reducción de Daño:** 90%
  - **Inmunidad:** Daño Mental
  - **Muleta**
    - Si el usuario se rompe los huesos o pierde extremidades, la armadura se mueve por el propio usuario hasta que este fallezca.
    - **Inmunidad:** Adormecido/Absoluto
      - El portador estará dormido, pero la armadura se moverá por él.
    - **Aumentos**
      - **Fuerza Final:** +30% **(F. Principal/Resistencia/Velocidad)**
    - **Inmunidad:** Sangrado/Absoluto
    - **Acción Adicional:** 1
- **Naturaleza**
  - **Físico:** Sólido
  - **Elemento:** Ninguno
- **Consumo**
  - **Daño Mental:** 50.000 x Turno Propio
    - No se pueden recuperar hasta finalizar el combate.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 0
  - **Logro:** Locura Interminable

# _**Integridad**_

## ᴛéᴄɴɪᴄᴀꜱ

**Ruptura del Yugo.** Una potente onda capaz de deshacerse de todas las habilidades del tipo trampa, así como también del eliminar otro tipo de restricciones a su alcance.

- **Propiedades**
  - **Rango:** 1 Categoría
    - **AOE**
  - **Despeje**
    - Todas las habilidades de tipo trampa de cualquier tipo desaparecerán.
  - **Anula:** Encarcelamiento/Absoluto
  - **Duración:** 5 Turnos
    - Durante este tiempo no se podrán volver a utilizar este tipo de habilidades.
- **Naturaleza**
  - **Físico/Karma-Natural:** Entorno
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 5.000
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 8 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5

## ᴘᴀꜱɪᴠᴀꜱ

**Influencia Corrupta.** Cuanto más tiempo pase un objetivo con restricciones, mayores serán los daños que podrán recibir, acumulándose este efecto constantemente. Estas acumulaciones desaparecen cuando dejan de estar restringidos.

- **Propiedades**
  - **Penetración:** 7% x Acumulación `〨Karma〨`
    - Lo sobrante se vuelve **daño crítico**.
      - Se va acumulando a medida que el objetivo está recibiendo **control mental, parálisis o cualquier cosa similar.**
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

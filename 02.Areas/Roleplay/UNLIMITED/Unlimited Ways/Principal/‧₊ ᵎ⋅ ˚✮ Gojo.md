## ꜰᴏʀᴍᴀꜱ

**Seis Ojos: Liberación.** Cuando el usuario se destapa los ojos, se revelan sus ojos de un azul brillante. Estos ojos entregan una visión muy avanzada del entorno, así como información detallada del karma, permitiendo utilizar de forma mucho más avanzada habilidades.

- **Estadísticas**
  - **Porcentaje:** 50% **(General)** `〨Hechicería〨`
- **Efectos Adicionales**
  - **Miedo Absoluto:** 7 Acciones
  - **Electrificación Absoluta:** 7 Acciones
- **Propiedades**
  - **Maestría Total:** +20% **(Hechicería)**
  - **Maestría Total:** +20% **(Mago)**
  - **Maestría Total:** +20% **(Brujo)**
  - **Aceleración de Cánticos**
    - Permite al usuario realizar el **doble** de cánticos de '**Hechicería**' por **acción**.
  - **Predicción:** 7 `〨Hechicería〨`
  - **Detección:** 7 `〨Hechicería〨`
  - **Acción Adicional:** +1
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.
  - **Puntos de Habilidad:** 5

**Euforia Ilimitada.** El núcleo de karma del usuario recibe una mutación debido a la gran euforia y acontecimientos del momento. Esto no solo permite al usuario salvarse a si mismo una vez incluso de la muerte, si no utilizar sus habilidades con un dominio muy avanzado de las mismas. **(Los beneficios de este estado se suman a los del anterior.)**

- **Estadísticas**
  - **Porcentaje:** 50% **(General)** `〨Hechicería〨`
- **Efectos Adicionales**
  - **Miedo Absoluto:** 7 Acciones
  - **Electrificación Absoluta:** 7 Acciones
  - **Torbellino Absoluto:** 7 Acciones
- **Propiedades**
  - **Maestría Total:** +35% **(Hechicería)**
  - **Maestría Total:** +35% **(Mago)**
  - **Maestría Total:** +35% **(Brujo)**
  - **Resurrección**
  - **Supremacía Absoluta**
  - **Aceleración de Cánticos**
    - Permite al usuario realizar el **triple** de cánticos de '**Hechicería**' por **acción** en vez del **doble**.
  - **Predicción:** 7 `〨Hechicería〨`
    - **Predicción Absoluta:** 4 `〨Hechicería〨`
  - **Detección:** 7 `〨Hechicería〨`
  - **Acción Adicional:** +1
  - **Maestría Total:** +35% **(???)**
    - Aplica a la maestría de la **regeneración de estado vital**. **(Ya sean formas, técnicas o pasivas**)
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000 x Turno
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 1 x Combate
    - Para activar este estado es necesario que anteriormente en la pelea el usuario haya utilizado un ‘**Destello Negro**' o una '**Expansión de Dominio**’.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 10

## ᴛéᴄɴɪᴄᴀꜱ

**Infinito.** Una técnica que distorsiona el espacio para crear una zona de distancia infinita alrededor del usuario. Cualquier objeto, ataque o energía que intente alcanzarlo es desacelerado hasta detenerse por completo, funcionando como defensa. **(Cada cambio en la barrera se especifica, gastan acción estos cambios.**)

- **Propiedades**
  - **Rango:** Dos Centímetros
    - **Permite** el uso de combate **cuerpo-a-cuerpo** por parte del usuario **(Aunque no de contacto directo)**.
      - **Defensa Natural**
        - Impide que técnicas crucen esta barrera a excepción de las siguientes:
          - **Gas**
          - **Sonido**
          - **Luz**
          - **Espacio-Temporal**
          - **Entorno**
          - **Potenciación**
          - **Temperatura**
          - **Anti-Magia**
  - **Rango:** Dos Metros
    - **Impide** el uso de combate **cuerpo-a-cuerpo** por parte del usuario.
      - **Defensa Natural**
        - Impide que técnicas crucen esta barrera a excepción de las siguientes:
          - **Sonido**
          - **Luz**
          - **Espacio-Temporal**
          - **Entorno**
          - **Potenciación**
          - **Anti-Magia**
- **Naturaleza**
  - **Karma-Mágico:** Barrera
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000 x Turno

**Infinito: Intensificación.** Permite al usuario intensificar la cantidad de potencia que desprende su barrera de '**Infinito**', esto funciona para deshacerse de técnicas de ciertas naturalezas que normalmente no detendría. Las técnicas contra las que se está intensificando la barrera deben de tener una maestría inferior.

- **Efectos Adicionales**
  - **Silencio:** 5 Acciones
  - **Ejecución**
    - Si el objetivo se pasa **5 Acciones** dentro de la barrera, este explotará, recibiendo **Ejecución** en todo su cuerpo.
- **Propiedades**
  - **Rango:** Cinco Metros
    - **Impide** el uso de combate **cuerpo-a-cuerpo** por parte del usuario.
      - **Defensa Natural**
        - Impide que técnicas crucen esta barrera a excepción de las siguientes:
          - **Anti-Magia**
- **Naturaleza**
  - **Karma-Mágico:** Barrera
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000 x Acción
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 0 Turnos
  - **Requisito**
    - Para funcionar se requiere tener **mayor** maestría de **Hechicería** que **maestría** tenga la **técnica** que se intenta detener.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5
  - **Seis Ojos**

- **Propiedades**
  - **Maestría Total:** +20% **(Hechicería)**
  - **Maestría Total:** +20% **(Mago)**

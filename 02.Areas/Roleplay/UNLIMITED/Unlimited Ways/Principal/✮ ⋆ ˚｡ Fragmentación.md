# ✮ ⋆ ˚｡ Fragmentación

![[f054d575b6d39fd0565c54879aabec71.jpg]]

**✦ Fragmentación.** Permite dividir técnicas en varios fragmentos que se pueden manipular a consciencia por el propio usuario, lo que permite volverlas multi-hit. Cada fragmento gasta energías formarlo, y los fragmentos inicialmente tienen una fuerza mucho menor del que tendría la técnica originalmente.

- **Propiedades**
  - **Rango:** 3 Zonas
    - **Multi-Target**
      - Adquiere **Multi-Target** cuando se alcanza **300%** de **maestría**.
  - **Daño:** 5% `〨Fragmentación〨`
    - Este es el daño que hará la técnica fragmentada tomando de referencia su daño original.
      - Cada **100%** de **maestría**, se añade +**5%**, lo que poco a poco hará que puedas fragmentar perdiendo menos potencia que de costumbre.
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 2.000 x Fragmento
  - **CD:** 0 Turnos

# ✮ ⋆ ˚｡ Aceleración (F)

![[b6dcd76c4e53b2b6f3a6a2b89ca1b892.jpg]]

**✦ Aceleración.** Permite incrementar la velocidad del usuario notoriamente. También puede utilizarse en objetivos ajenos al usuario, por ejemplo aliados.

- **Estadísticas**
  - **Suma:** 100 **(Velocidad)** `〨Aceleración〨`
  - **Porcentaje:** 10% **(Velocidad)** `〨Aceleración〨`
- **Efectos Adicionales**
  - **Evasiva** `〨Aceleración〨`
    - El usuario puede elegir si colocar en **cooldown** su propio slot de evasiva o el del aliado al que está apoyando en caso de estar apoyando a uno.
      - Si se alcanza **500%** de maestría, pasará a ser **Evasiva Absoluta**.
  - **Counter** `〨Aceleración〨`
    - El usuario puede elegir si colocar en **cooldown** su propio slot de counter o el del aliado al que está apoyando en caso de estar apoyando a uno.
      - Si se alcanza **500%** de maestría, pasará a ser **Counter Absoluto**.
- **Propiedades**
  - **Rango:** 3 Zonas
  - **Supremacía**
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
    - **Aguante:** 5.000 x Turno
      - Si se intenta utilizar en otros objetivos que no son el propio usuario, **sí** gastará energías.
  - **CD:** 0 Turnos

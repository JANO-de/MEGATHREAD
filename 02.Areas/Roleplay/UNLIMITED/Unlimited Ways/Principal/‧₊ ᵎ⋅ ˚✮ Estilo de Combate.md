**Rotación Avante: Destello Azul.** Permite utilizar '**Azul**' en si mismo para movilizarse a velocidades instantáneas como método de desplazamiento.

- **Propiedades**
  - **Rango:** Indefinido
  - **Teletransporte** `〨Hechicería〨`
    - Se vuelve **absoluto** si tienes **1.000%** de **maestría**.
- **Naturaleza**
  - **Karma-Mágico:** Espacio-Temporal
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Puntos de Habilidad:** 3
  - **Rotación Avante: Azul Máximo**

**Rotación Avante: Azul Espacial.** Mediante combinar los conceptos de ‘**Azul**' y '**Rojo**’ el usuario es capaz de controlar el espacio a su propio alrededor para hacerse flotar a si mismo o quienes está tocando.

- **Estadísticas**
  - **Porcentaje:** 30% **(Velocidad)** `〨Hechicería〨`
- **Propiedades**
  - **Evasión Absoluta:** 10%
  - **Vuelo**
- **Naturaleza**
  - **Karma-Mágico:** Espacio-Temporal
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 5.000 x Turno
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5
  - **Rotación Avante: Azul Máximo**
  - **Rotación Inversa: Rojo Diferido**

**Rotación Avante: Núcleos Planetarios.** Esto es un estilo de combate que permite recubrir constantemente de '**Azul**' los puños del usuario, esto no actúa como un punto de atracción exactamente, si no que se dedica a condensar esa presión fuertemente, lo que puede provocar daños internos en quienes son golpeados.

- **Estadísticas**
  - **Porcentaje:** 20% **(F. Karma)** `〨Hechicería〨`
- **Efectos Adicionales**
  - **Sangrado Absoluto:** 4 Acciones
  - **Contusión Absoluta:** 4 Acciones
- **Propiedades**
  - **Supremacía Absoluta**
  - **Penetración:** 4% `〨Hechicería〨`
    - Lo sobrante se volverá **daño crítico**.
  - **Perforación Celestial:** 10%
    - Será **20%** si tienes **Seis Ojos: Liberación** activo.
  - **F. Física → F. Karma**
    - Solo aplica en **técnicas** de **Fuerza**.
- **Naturaleza**
  - **Karma-Mágico:** Espacio-Temporal/Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000 x Turno
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Puntos de Habilidad:** 4
  - **Rotación Avante: Azul Máximo**
  - **Seis Ojos: Liberación**

**Rotación Avante: Destello Múltiple.** Permite utilizar de manera ultrarrápida '**Destello Azul**' para movilizarse, generando imágenes residuales las cuales son capaces de proporcionar apoyo al usuario temporalmente. **(No gasta acción utilizar esta técnica.)**

- **Estadísticas**
  - **Porcentaje:** 30% **(Velocidad)** `〨Hechicería〨`
- **Propiedades**
  - **Rango:** 5 Zonas
  - **Duración:** 1 Turno
  - **Acción Adicional:** +1 x Imagen
  - **Limite de Imágenes:** 1 `〨Hechicería〨`
    - Cada **500%** de **maestría** se añade **+1 Imagen**.
      - Se salta el limite.
- **Naturaleza**
  - **Karma-Mágico:** Espacio-Temporal
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 5.000 x Imagen
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 8 Turnos
  - **Seis Ojos: Liberación**
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5
  - **Rotación Avante: Azul Máximo**

  - **Suma:** 200 **(Velocidad)** `〨Hechicería〨`
- **Efectos Adicionales**
  - **Ejecución**
  - **Sangrado Absoluto:** 4 Acciones

  - **Rango:** 4 Zonas

  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 4.000 x Objetivo

  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Puntos de Habilidad:** 4

## ᴘᴀꜱɪᴠᴀꜱ

**Prodigio.** Esta familia es de un linaje de espadachines bendecidos, lo que les proporciona grandes aptitudes.

- **Propiedades**
  - **Maestría Total:** +35% **(Especialidades)**
  - **Maestría Total:** +35% **(Respiración)**
    - También proporciona adicionalmente **+35%** para **todas** las maestrías que puedan utilizar los **Estilos de Respiración**.
  - **Mente Abierta**
    - Cuando el usuario adquiere este clan, el clan ‘**Tokito**' se fusiona a este clan y puede usar el slot de clan que le ocupaba '**Tokito**’ para otro clan diferente.
  - **Respiración Completa**
    - El usuario tendrá todo esto desbloqueado gratuitamente aun sin ser del rango requerido.

## ᴛéᴄɴɪᴄᴀꜱ

**Garras de Unión.** Estas son unas garras las cuales tienen la capacidad de unirse de manera permanente con cualquier otro **armamento** que haya ingerido previamente el usuario, no se cuentan objetos repetidos.

- **Estadísticas**
  - **Suma:** 5.000 **(F. Principal)**
  - **Suma:** 15.000 **(Velocidad)**
- **Efectos Adicionales**
  - **Hemorragia:** 7 Acciones
  - **Sangrado:** 7 Acciones
- **Propiedades**
  - **Inmunidad:** Quiebre Absoluto
  - **Supremacía** `〨Hechicería〨`
    - Cuando llegas a **1.000%** de **maestría** se vuelve **absoluto**.
  - **Unión de Guerra**
    - Todos los **armamentos** que haya ingerido el usuario serán utilizados para potenciar estas garras.
      - Se añaden las **estadísticas** de esos **armamentos**.
      - Se añaden las **habilidades** de esos **armamentos**.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Información del Objeto**
  - **Tipo de Armamento:** Garras.
    - **Porcentaje:** +20% **(Fuerza Principal)**
    - **Porcentaje:** +30% **(Velocidad)**
      - **Sangrado:** +100%
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Puntos de Habilidad:** 4

  - **Elemento:** Ninguno

  - **Aguante:** 0

**Expansión de Dominio: Lugar de Origen.** Este es un dominio con la capacidad de recrear de manera exacta un escenario por el que el usuario sienta gran aprecio. Dentro de este dominio ‘**Shrine**' y '**Desmantelar Espiritual**’ causarán **ejecución** directamente, ya sea física o espiritual.

- **Efectos Adicionales**
  - **Encarcelamiento Absoluto:** Dominio Completo
- **Propiedades**
  - **Rango:** 3 Zonas
  - **Maestría Total:** +400%
    - Aplica a todas las maestrías que estén relacionadas con las habilidades que están vinculadas a tu dominio.
  - **Ejecución**
    - Lo tendrán ‘**Shrine**' y '**Desmantelar Espiritual**’.
      - **Shrine** es una ejecución **física**.
      - **Desmantelar Espiritual** es una ejecución **espiritual**.
  - **Reconocimiento de Hogar**
    - El usuario podrá utilizar las habilidades de **dos** personas.
      - Estas personas deben ser **amigos**, y no pueden estar dentro de este dominio.
        - Si están dentro del dominio puedes elegir a otros sujetos que también cumplan con las condiciones.
        - La **maestría** que proporciona este dominio se aplicará también para **todos** los **aliados** del usuario.
  - **Dominio Completo**
  - **Golpe Seguro**
- **Naturaleza**
  - **Karma-Mágico:** Entorno/Potenciación
  - **Elemento:** Ninguno
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Expansión de Dominio**
  - **Puntos de Habilidad:** 7

**Recipiente Maldito.** El usuario es capaz de contener en su interior a cualquier criatura que requiera de un recipiente, por ejemplo a '**Sukuna**'. A su vez, si ingiere objetos será capaz de utilizar las habilidades vinculadas a estos mismos. Además, el usuario es bastante resistente gracias a su estado vital incrementado.

- **Propiedades**
  - **Aumentos Pasivos**
    - **Aguante:** +x1 **(Pasivo)**
    - **F. Física:** +x2 **(Pasivo)**
    - **F. Karma:** +x1 **(Pasivo)**
    - **Velocidad:** +x2 **(Pasivo)**
    - **Resistencia:** +x2 **(Pasivo)**
  - **Estado Vital:** 30.000 `〨Hechicería〨`
  - **Inmunidad Mental:** 7 `〨Hechicería〨`
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

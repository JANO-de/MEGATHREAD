# ✮ ⋆ ˚｡ Control

![[image_(7).png]]

**✦ Control.** Cuando el usuario derrota a su contrincante de alguna manera, ya sea en un juego o un combate, ese objetivo se contará como si tuviese menos estadísticas en cada ocasión cada que repitan el combate. Si el objetivo derrota al usuario en alguna, se recuperará un poco de esa desventaja.

- **Estadísticas**
  - **Suma:** -500 x Derrota **(General)** `〨Control〨`
- **Propiedades**
  - **Aprendizaje Forzado**
    - Si el usuario acumula **cinco victorias** contra el mismo objetivo, puede elegir aprender una habilidad a elección del objetivo. Esto no se pierde aunque el objetivo gane al usuario alguna vez.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos

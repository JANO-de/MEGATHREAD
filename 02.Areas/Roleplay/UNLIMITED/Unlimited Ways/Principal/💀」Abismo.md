**Engaño del Diablo.** Aunque el usuario pierda estado vital máximo, todas aquellas habilidades que escalen con esto mismo, contarán como si el usuario no hubiese perdido estado vital máximo. Si el objetivo pierde estado vital máximo, el usuario podrá seguir contando las habilidades como si el objetivo no lo hubiese perdido.

- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Abismo
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 1

**Novaburst.** Se dispara una potente explosión la cual se vuelve más fuerte dependiendo de cuanta vitalidad máxima tenga el usuario. Cada vez que esta técnica es utilizada y acertada, la vitalidad máxima del usuario se incrementa.

- **Estadísticas**
  - **Daño Verdadero/Mental:** 3% **(F. Karma)**
    - **Suma:** 150 **(F. Karma)** `〨Abismo〨`
      - Cada **300.000** de **Vitalidad Máxima** que tengas, se aumentará su **daño verdadero/mental** en **+1%**.
        - **Limite:** El máximo que le puedes aumentar es hasta que la habilidad sea de **20%**.
- **Efectos Adicionales**
  - **Miedo:** 3 Acciones
  - **Corrupción:** 3 Acciones
- **Propiedades**
  - **Rango:** 3 Zonas
    - **AOE**
  - **Vitalidad Máxima:** +2.000 `〨Abismo〨`
- **Naturaleza**
  - **Karma-Mágico:** Luz
  - **Elemento:** Abismo
- **Consumo**
  - **Aguante:** 3.000
  - **CD:** 6 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Superior.
  - **Entrenamiento:** Calidad ‘_Media_’.
  - **Puntos de Habilidad:** 3

  - **Rango:** 5 Zonas

  - **Supremacía Absoluta**

**Estado de Completa Corrupción.** El usuario manifiesta una gran oscuridad representando el abismo que lo domina. Mientras dure este estado, el usuario perderá al final de cada turno una cantidad fija de vitalidad, a cambio de varios beneficios. Este estado aunque se desactive, se contarán los buffos y debuffos de ese mismo turno. (**Para en el siguiente ya no estar.**)

- **Estadísticas**
  - **Porcentaje:** 50% **(General)** `〨Abismo〨`
- **Efectos Adicionales**
  - **Miedo:** 7 Acciones
  - **Corrupción:** 7 Acciones
- **Propiedades**
  - **Daño Verdadero:** +0,1% `〨Abismo〨`
  - **Daño Tóxico:** +0,1% `〨Abismo〨`
  - **Daño Mental:** +0,1% `〨Abismo〨`
  - **Daño Espiritual:** +0,1% `〨Abismo〨`
    - Estos daños se suman al tipo de daño que realices.
      - **Limite:** Máximo puedes aumentarlos **+5%**.
- **Naturaleza**
  - **Karma-Mágico:** Potenciación
  - **Elemento:** Abismo
- **Consumo**
  - **Aguante:** 10.000 x Turno
    - **Vitalidad Máxima:** 20.000 x Turno
      - Se puede elegir otro tipo de estado vital.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Entrenamiento:** Calidad ‘_God_’.
  - **Puntos de Habilidad:** 7

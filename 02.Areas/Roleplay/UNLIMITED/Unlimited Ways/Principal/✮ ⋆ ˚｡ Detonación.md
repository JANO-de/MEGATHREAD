# ✮ ⋆ ˚｡ Detonación

![[2da2df57a63193d1f7c139bf528be207.jpg]]

**✦ Detonación.** La vitalidad del usuario se vuelve un combustible el cual esta habilidad utiliza para provocar explosiones de gran magnitud. Cuando el usuario **fallece**, se libera una **detonación final** la cual equivale a una explosión que ha consumido una vitalidad equivalente a la **vitalidad máxima** del usuario.

- **Estadísticas**
  - **Daño Verdadero:** 7% **(F. Principal)**
    - **Suma:** 500 **(F. Principal)** `〨Detonación〨`
- **Efectos Adicionales**
  - **Corta Regeneración**
- **Propiedades**
  - **Rango:** 1 Zona
    - **AOE**
  - **Supremacía**
    - Si se utiliza **100.000 o más** vitalidad, se vuelve **Supremacía Absoluta**.
  - **Penetración:** 7% `〨Detonación〨`
    - Cada vez que se consigue **100%** de **maestría** se adquiere **+7%** de penetración.
- **Naturaleza**
  - **Físico:** Temperatura
  - **Elemento:** Ninguno
- **Consumo**
  - **Vitalidad:** 50.000
    - La vitalidad que se vaya gastando a lo largo del combate no se podrá recuperar hasta que el propio combate finalice, o hasta que pasen **20 Turnos**.
      - Se puede multiplicar el consumo de vitalidad para formar una explosión de mayor magnitud, ya que cada **50.000**, se acumula la potencia si aun no se ha expulsado. (**Todo se acumula menos la penetración.**)
  - **CD:** 0 Turnos

**Recompensa de la Experiencia.** Cuando el usuario ha creado cierta cantidad de veces un experimento no relacionado al material genético, este comenzará a recibir varios ejemplares de la misma creación al crearla nuevamente.

- **Propiedades**
  - **Cantidad de Resultado de Fabricación:** +100% `〨Investigador〨`
    - Solo aplica con objetos que hayan sido creados al menos **tres veces previamente** por el **usuario**.
      - Cada **1.000%** de **maestría**, se añade otro **+100%**.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 1

**Robótica Servicial.** Permite crear robots capaces de ayudarlo con tareas básicas. Estos robots pueden tener de base instaladas unas cámaras para grabar todo lo que presencian, así como también alarmas. El usuario puede colocarles una IA de **combate**, la cual les permitirá usar **especialidades** de las cuales el **usuario** tenga **registros**.

- **Propiedades**
  - **Robots**
    - **Sistema de Grabación**
      - Pueden tener grabado todo lo que presencian.
    - **Sistema de Alarmas**
      - Pueden enviar señales de alarma a ciertos dispositivos que el usuario marque, o hacer sonar una alarma.
    - **IA de Combate**
      - Pueden tener especialidades previamente examinadas por el usuario, pero solo una a la vez por robot.
      - Los robots tienen los mismos **puntos de estadística** que el usuario, **multiplicadores y demás**, pero **no tienen maestría**.
    - **IA Secundaria**
      - Pueden tener en vez de una especialidad principal, una secundaria como por ejemplo **investigador**, **alquimista** y demás.
      - No pueden usarse para crear más robots o criaturas.
      - Pueden usarse para estar creando varios objetos a la vez con un mismo mensaje.
      - También pueden usarse para recolectar varios materiales a la vez.
        - No se le aplican los aumentos de recolección.
    - **Limite:** 5 Robots
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
    - **No requieren de materiales.**
  - **CD:** 30 Días `〨Investigador〨`
    - Cada **100%** de **maestría**, se reduce **1 día**.
      - **Reparar no cuesta cooldown, pero se necesita recuperar los restos del robot.**
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Medio.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 2

**Extracción de Muestras.** El usuario puede extraer y conservar con precisión cualquier material genético sin desperdiciarlo, además de identificar la habilidad que contiene con solo analizarlo una vez.

- **Propiedades**
  - **Funcionamiento**
    - Inyecta una jeringuilla que extrae la muestra genética.
    - Esta muestra luego puede inyectarse en otro para adquirir la habilidad ligada a la muestra.
      - **Implantes** que hayan sido inyectados en el pasado, se pueden re-extraer para liberar ese slot. Sin perder la muestra.
    - **Limite**
      - Puede obtener **una** muestra de **cada apartado en criaturas vivas**.
        - O hasta **tres** muestras de **cada apartado en cadáveres**.
    - **Implantes**
      - El **máximo** de implantes que se pueden tener a la vez es de **diez**.
        - Este limite es entre **clanes** y **razas**.
          - Las únicas excepciones son clanes o razas que posean naturalmente capacidades de copia o absorción genética, ya que estos pueden asimilar las muestras sin consumir espacios del límite.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Entrenamiento:** Calidad ‘_Alta_’.
  - **Puntos de Habilidad:** 5

**Juego Divino.** Permite utilizar material genético de cadáveres para así crear un nuevo ser, incluso tomando rasgos específicos de varios seres para como quien dice, rellenar una ficha nueva. (**Se pueden llegar a crear varias.**)

- **Propiedades**
  - **Criatura**
    - Esta criatura tendrá la misma cantidad de **puntos de estadística** que su **creador**.
    - Igual que los robots, esta criatura podrá tener **especialidades** según los **registros** que el **creador** le implante. Pero también podrá tener **elementos**.
      - Sus limites de **especialidades** y **elementos** son los que un personaje normalmente podría tener.
        - Su maestría se puede entrenar, pero de base será equivalente a la maestría **base** que tiene el usuario en investigador, contando la absoluta. Esta maestría se puede colocar en hasta:
          - **Maestrías:** 1 `〨Investigador〨`
          - Cada **500%** de **maestría** puedes aplicar la **maestría final** a un apartado más.
    - **Raza/Clan Principal:** 1
      - **Raza/Clan Secundario:** 1
      - **Raza/Clan Evolucionado:** 1
        - No necesita **puntos de habilidad** para desbloquear algo de esto.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
    - **Proceso de Fabricación:** Calidad 'God'
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 0
  - **Logro:** Retador de Moralidades

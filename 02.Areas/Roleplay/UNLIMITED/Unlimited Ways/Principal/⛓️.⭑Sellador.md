**Extracción de Residuos.** Permite formar unos sellos los cuales son capaces de almacenar no solo objetos, si no también karma, dentro de recipientes de algún tipo, por ejemplo papeles sin consumir espacio del inventario del usuario. Cuanto más se domina esta especialidad, más sellos de este tipo pueden formarse, permitiendo ir cada vez más ligero gracias a sus sellos. Para almacenar karma, debe estarse haciendo el intento de sellado durante por lo menos un turno completo dentro de combate. Fuera de combate se requiere al menos de una **narración** de **calidad media**. Para que lo que hay dentro del sello sea liberado, se necesita que el propio usuario lo libere, o que el recipiente sea destruido. (**Puede atrapar incluso Anti-Magia, pero no resistirla una vez tienen algo dentro los sellos.**) (**El recipiente puede ser un ser vivo, pero guardar karma dentro de este no hará que pueda utilizar ese karma almacenado.**)

- **Estadísticas**
  - **Suma:** 50 **(Velocidad)** `〨Sellador〨`
- **Efectos Adicionales**
  - **Sellado**
- **Propiedades**
  - **Sellos de Almacenamiento:** 1 `〨Sellador〨`
  - **Rango:** Contacto Físico
- **Naturaleza**
  - **Karma-Mágico:** Entorno
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 1.000
  - **CD:** 4 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 1

**Sellado de Criaturas.** Permite sellar criaturas en recipientes, se requiere cierto nivel de maestría para cada rango a sellar. Tan solo se debe tocar al objetivo y aplicar sello mientras está **adormecido**, en **parálisis** o **bajo los efectos de control mental aliado**. (**Sellar una criatura no implica que puedas usar sus habilidades, significa atraparla en sentido literal. Pero hay casos donde sí se puede llegar a sacar habilidades de estas criaturas, por ejemplo si lo sellado es un personaje capaz de transferir habilidades y lo hace por voluntad propia, o si son criaturas como por ejemplo las Bestias con Cola.**)

- **Estadísticas**
  - **Suma:** 100 **(Velocidad)** `〨Sellador〨`
- **Efectos Adicionales**
  - **Sellado Absoluto**
    - No se requiere maestría para sellar una criatura de **rango bajo**.
      - Se requiere **100%** de **maestría** para sellar una criatura de **rango medio.**
      - Se requiere **200%** de **maestría** para sellar una criatura de **rango superior.**
      - Se requiere **400%** de **maestría** para sellar una criatura de **rango especial.**
      - Se requiere **600%** de **maestría** para sellar una criatura de **rango celestial.**
      - Se requiere **800%** de **maestría** para sellar una criatura de **rango eterno.**
      - Se requiere **1.000%** de **maestría** para sellar una criatura de **rango estelar.**
- **Propiedades**
  - **Rango:** Contacto Físico
- **Naturaleza**
  - **Karma-Natural:** Entorno
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 2.000
  - **CD:** 5 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Medio.
  - **Entrenamiento:** Calidad ‘_Baja_’.
  - **Puntos de Habilidad:** 2

**Caricia del Confinamiento.** Permite sellar dentro de uno de sus **recipientes de extracción**, los **recuerdos de una criatura**. También puede **meter recuerdos nuevos junto a los antiguos, o dejar solo unos nuevos**. Estos recuerdos también se los puede colocar el usuario a si mismo. (**Esta habilidad puede usarse para atajar el procedimiento de habilidades de copia o similar que requieran del conocimiento de otras antes. También puede usarse para saltarse el proceso de aprendizaje de una habilidad en especifico que el objetivo que recibe estos recuerdos, pueda aprender. Si el usuario extrae recuerdos sobre un elemento y se lo entrega a otro, esa persona podrá usar ese elemento con todo aprendido hasta donde tuviese la otra persona, pero la otra persona olvidará todo lo extraído de su cabeza. **Liberación Forzada.** Permite que a cambio de **gastar un sello de recipiente**, se utilice el **karma que hubiese almacenado dentro de ese mismo** para **usar la habilidad** que se estuviese **guardando**. Si era una **pasiva o modo** durará el **resto de la pelea**, si era una **técnica** se podrá utilizar durante el **resto del combate también**, siempre **respetando el consumo**, pero **ignorando el rango y método de desbloqueo**. (**También pueden hacer que las tenga otro aliado en vez del usuario, o que las tenga el objetivo y forzarlo a usarla.**)

- **Estadísticas**
  - **Suma:** 500 **(Velocidad)** `〨Sellador〨`
- **Propiedades**
  - **Rango:** Contacto Físico
  - **Duración:** Combate Completo
- **Naturaleza**
  - **Karma-Natural:** Entorno
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
    - **Sello de Almacenamiento**
      - Luego del combate se pierde aquello que había dentro del sello.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 0
  - **Logro:** Secretos del Karma

**Mahoraga: Rueda de Adaptación.** Permite analizar cualquier fenómeno que impacte al usuario para generar una adaptación contra él, girando una vez por turno a cada cosa. La rueda es compartida: quien la lleve puesta en ese momento es quien obtiene las adaptaciones. Cada vez que el fenómeno se repite, la rueda avanza y acelera el proceso de análisis, hasta varias veces por turno. Una vez completado, la adaptación queda permanente, salvo que la rueda sea destruida.

- **Rueda de Ocho Empuñaduras**
  - Cada **giro repetido** adelantará **2 turnos** el análisis.
  - Si intentas adaptarse a más de una de estas cosas, se suma el tiempo para cada una aunque te adaptarías progresivamente a estas mismas.
  - Una vez adaptado puedes **absorberlas**, **reflejarlas**, **destruirlas** y más sin ningún tipo de problema.
  - Si los fenómenos a los que te adaptaste te dejaron daños o similar que siguen perdurando, podrás deshacerlos aunque hayan ocurrido antes de adaptarte. **(Por ejemplo curarte los daños completamente o desvanecer los efectos**)
    - **Naturalezas**
      - Si el fenómeno es intocable por naturaleza, la habilidad hace que el usuario pueda interactuar con él, y así adaptarse para poder tocarlo siempre. **(Esto incluye** también **presencia nula/camuflaje** y **teletransportes**.)
        - **2 Turnos Propios**
    - **Efectos Adicionales**
      - Si un efecto o daño afecta al usuario, puede analizarlo para volverse inmune, pero solo contra esa misma habilidad de origen.
        - **4 Turnos Propios**
    - **Territorios/Golpe Seguro**
      - Si el fenómeno ignora inmunidades o adaptaciones, la rueda aún puede analizarlo, pero tarda más tiempo. La adaptación será solo contra esa habilidad específica; por ejemplo, adaptarse a un dominio concreto permitiría incluso romperlo desde dentro.
        - **8 Turnos Propios**
- **Naturaleza**
  - **Karma-Mágico:** Invocación
    - **Karma-Mágico:** Potenciación **(Rueda)**
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 20.000
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Especial.
  - **Puntos de Habilidad:** 0

**Factor RC.** Las células RC otorgan regeneración y otras capacidades. Solo pueden consumir carne humana. Aumentan su fuerza y el poder de su kagune con cada ser devorado, evolucionando según la cantidad de presas consumidas.

- **Propiedades**
  - **Maestría Total:** +20% **(Esp. Principales)**
  - **Maestría Total:** +20% **(Trampista)**
  - **Maestría Total:** +20% **(Berserker)**
  - **Maestría Total:** +20% **(Acróbata)**
  - **Maestría Total:** +20% **(Artillero)**
  - **Maestría Total:** +20% **(Investigador)**
  - **Maestría Total:** +20% **(Mecánico)**
  - **Maestría Total:** +20% **(Tanque)**
  - **Maestría Total:** +20% **(Alquimista)**
  - **Maestría Total:** +20% **(Manipulador)**
  - **Maestría Total:** +20% **(Sangre)**
  - **Alimentación**
    - **Porcentaje:** 20% x Cuerpo **(General)** `〨Berserker〨`
      - Esto es lo que proporciona devorar cuerpos de **bosses/personajes**.
  - **Regeneración de Estado Vital:** 0,1% x Turno `〨Berserker〨`
    - Aplica a **Vitalidad**, **Toxicidad** y **Cordura**.
  - **Recuperación de Aguante:** 4.000 x Turno `〨Berserker〨`
  - **Canibalismo**
    - Esta raza se vuelve más poderosa a medida que el usuario devora a otras criaturas.
      - Si el usuario durante un combate devora a alguien aunque sea parcialmente, tendrá su experiencia incrementada durante el resto del combate de manera **no** acumulativa.
        - **Experiencia (B.R):** +100%
        - **Puntos de Habilidad (B.R):** +100%
      - Además, se le añadirá también maestría adicional a repartir entre cualquier maestría.
        - **Maestría:** +20%
          - Se reparte entre maestrías a elección del usuario.
          - Se deben respetar los requisitos de **calidad** para obtener **maestría**.
          - **CD:** 2 Turnos Propios
        - **Maestría Total:** +4%
          - Se reparte entre maestrías a elección del usuario.
          - Se debe hacer **calidad ‘Alta’.**
          - **CD:** 2 Turnos Propios
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

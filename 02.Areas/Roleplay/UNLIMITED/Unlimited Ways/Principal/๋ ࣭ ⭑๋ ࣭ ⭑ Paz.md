## Todos pueden utilizar estas habilidades, incluyendo los **Restringidos**.

**Repelente de Judas.** El primer turno enemigo que logre acertar contra el usuario causará menos daños comparado a los originales. Por ejemplo, si entre todas las habilidades se hace **100** de **cualquier tipo de daño**, ese daño se restará por el porcentaje de reducción de esta habilidad.

- **Propiedades**
  - **Reducción de Daño:** 5% `〨Paz〨`
    - Aplica a todo tipo de daño.
      - Si durante este turno el usuario aun así se ve forzado a utilizar “**Protección Instintiva**“, no se pondrá esa habilidad en cooldown.
- **Naturaleza**
  - **Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

**Momento de Urgencia.** Las habilidades curativas del usuario tendrán su cooldown reducido notoriamente.

- **Propiedades**
  - **Cooldown Máximo Reducido:** -1 Acción/Turno `〨Paz〨`
    - Cada **300%** de **maestría** se coloca otro **-1 Acción/Turno**.
      - El **cooldown máximo** puede reducirse como mucho hasta la **mitad** del **cooldown original**.
- **Naturaleza**
  - **Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 0 Turnos
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Medio.

**Protección Instintiva.** Cuando un aliado o el propio usuario estén por recibir un golpe que se supone que los mataría, estos se quedan solo en “casi”, sobreviviendo al ataque, en caso de ser por un efecto o similar este efecto será disipado. Solo puede utilizarse una vez por combate pero puede ocurrir en varios aliados a la vez en caso de que estos recibiesen el golpe fatal en el mismo **turno**.

- **Propiedades**
  - **Rango:** 1 Categoría
- **Naturaleza**
  - **Karma-Natural:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0
  - **CD:** 1 x Combate
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.

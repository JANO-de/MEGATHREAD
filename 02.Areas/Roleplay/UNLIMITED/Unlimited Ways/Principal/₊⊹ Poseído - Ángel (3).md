## ᴘᴀꜱɪᴠᴀꜱ

**Tiempo Vital.** Su habilidad principal le permite robar al contacto físico directo la longevidad de los seres vivos **(personajes/bosses)**, lo cual afecta a todo el estado vital al mismo tiempo aunque a la hora de acumular longevidad se contará solo el estado vital más elevado del objetivo.

- **Propiedades**
  - **Maestría Total:** +20% **(Luz)**
  - **Maestría Total:** +20% **(Aurora)**
  - **Maestría Total:** +20% **(Clérigo)**
  - **Maestría Total:** +20% **(Guerrero)**
  - **Absorción de Longevidad**
    - El usuario es capaz de arrebatar al **contacto físico directo** la longevidad de alcanzados de forma permanente. **(Estado Vital Máximo)**
      - El **Estado Vital Máximo** arrebatado no se junta con el del usuario, si no que se guarda a parte pero sin poder usarse como barra de vida pero sí para sus habilidades.
      - Si una habilidad drena algo de **Estado Vital Máximo** se puede utilizar este acumulado para esa habilidad aunque no se podrá recuperar.
      - Arrebatas a todo el **Estado Vital Máximo** a la vez, pero solo te llevas el más alto de estos.
        - **Robo de Longevidad:** 0,7% x Acción `〨Guerrero〨`
        - **Rango:** Contacto Físico Directo
          - También se puede a través de armas de corto alcance y sus propias alas.
    - Es capaz de saber en todo momento cuanta longevidad le queda a cualquier criatura que está mirando directamente.
  - **Longevidad Bendecida**
    - El usuario recibe **10.000** de **Longevidad** cada **24h**.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

# **¿Qué hace un Estasis (Tiempo Detenido)?**

### **﹁** **Detiene por completo al afectado**, parando el flujo del tiempo para este, lo que implica que no puede moverse, pensar, absolutamente nada. Solo alguien que es capaz de detener el tiempo puede moverse, si lo que le permite moverse no es una pasiva o estado, si no una técnica, debe gastarla durante el tiempo que quiera moverse, si por lo que sea sobra tiempo, puede seguir manteniéndose para aplicar este mismo efecto a otros. Solo se pueden sufrir **5 segundos** de **stun seguidos**, a no ser que el que lo aplica tenga algo que le permita sobrepasar este límite. (**Stun**, **Silencio** y **Tiempo Detenido** entran dentro del mismo pack en este caso. Si se aplican varios a la vez, **prevalece el mejor de ellos**.)

# **Efectos**

### **﹁** La **velocidad** del **afectado** se contará como si fuese **nula**. (**Si por lo que sea el afectado se enfrenta a otro personaje que tiene velocidad nula, será más rápido el que originalmente lo fuese.**)

### **﹁** El **afectado NO** puede moverse de su posición por si mismo. Lo mismo aplica para aquellas criaturas que controle desde la distancia, como por ejemplo **invocaciones**.

### **﹁** El **afectado NO** puede hacer **absolutamente nada** durante este efecto.

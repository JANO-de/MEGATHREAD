# ✮ ⋆ ˚｡ Descontrol

![[d80b998b03d9515db31b5e92a5ea62a6.jpg]]

**✦ Descontrol.** Esto actúa como mejora de '_Anulación_'. Cada vez que se anule una habilidad, se aplicarán daños en el cuerpo del objetivo.

- **Estadísticas**
  - **Daño Verdadero:** 0,7% `〨Descontrol〨`
- **Efectos Adicionales**
  - **Bloqueo de Habilidad**
    - No podrán utilidad habilidades primordiales anuladas por esta habilidad. Se debe dar una habilidad primordial propia del mismo grado o más para anular habilidades ajenas.
      - **Anulación:** 1 `〨Descontrol〨`
        - Por cada **500%** de **maestría**, cada habilidad propia que te anules servirá para anular **una más** del oponente.
- **Propiedades**
  - **Rango:** 1 Categoría
    - Si salen del rango de esta habilidad, dejarán de tener las habilidades anuladas, aunque las habilidades que tú diste a cambio de anular esas, las recuperarás.
- **Naturaleza**
  - **Anti-Magia:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000
  - **CD:** 0 Turnos

**Instinto Demoníaco.** Este es un estado donde se exprime el uso de toda la sangre recolectada, incrementando las capacidades propias significativamente.

- **Estadísticas**
  - **Porcentaje:** 30% **(General)** `〨Sangre〨`
- **Propiedades**
  - **Supremacía Absoluta**
  - **Regeneración de Estado Vital:** 5.000 x Turno `〨Sangre〨`
    - Aplica a **Vitalidad**, **Toxicidad**, **Cordura**.
  - **Penetración:** 5% `〨Sangre〨`
    - Lo sobrante se volverá **Daño Crítico**.
  - **Aumento de Maestrías**
    - **Maestría Total:** +25%
      - Aplica en todas las maestrías del usuario.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 5.000 x Turno
    - No se aplica el **Nivel de Drenaje**.
  - **CD:** 0
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Celestial.
  - **Puntos de Habilidad:** 5

**Rey Demonio.** Estado que se alcanza cuando el usuario se alza por encima de su propia raza. Proporciona acceso a un **Arte de Sangre Demoníaca** adicional, y la capacidad de regenerarse incluso mientras aun está recibiendo los ataques. **(Se puede acumular con las fases anteriores.)**

- **Estadísticas**
  - **Porcentaje:** 50% **(General)** `〨Sangre〨`
- **Propiedades**
  - **Supremacía Absoluta**
  - **Regeneración de Estado Vital:** 10.000 x Turno `〨Sangre〨`
    - Aplica a **Vitalidad**, **Toxicidad**, **Cordura**.
    - **Reducción de Daño:** 0,7% `〨Sangre〨`
  - **Aumento de Maestrías**
    - **Maestría Total:** +35%
      - Aplica en todas las maestrías del usuario.
  - **Regeneración Suprema**
    - La **regeneración de estado vital** del usuario no se aplicará después de recibir daños, si no mientras los recibe. Lo que le permite regenerarse de cada ataque recibido al instante, esto no le permitirá regenerarse de ataques que lo matarían directamente.
    - Si el usuario recibe **Corta/Inhabilita Regeneración** lo que ocurrirá no será que su regeneración se perderá, si no que se reducirá a la **mitad**.
  - **Arte de Sangre Demoníaca Real**
    - El usuario puede tener adicionalmente **cualquier** Arte de Sangre Demoníaca.
    - Adicionalmente tendrá también la propia de **Rey Demonio**.
- **Naturaleza**
  - **Físico:** Potenciación
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 0 x Turno
  - **CD:** 0
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Estelar.
  - **Puntos de Habilidad:** 7
  - **Slots:** 2
    - Solo pueden existir una cantidad limitada de **Reyes Demonio**.
  - **Condiciones**
    - Se requiere tener **todas** las **formas** previas desbloqueadas.
    - Se requiere ser bien **reconocido** para este puesto.

**Nacimiento Demoníaco.** Los demonios son criaturas de capacidades regenerativas muy significativas, así como también tienen una gran fortaleza pasiva en casi todas sus características. Tienen sentidos muy afilados, una gran memoria y un incremento de fuerzas a medida que se alimenta de seres vivos. Por ultimo, tienen acceso a **UN Arte de Sangre** **Demoníaca**.

- **Propiedades**
  - **Maestría Total:** +20% **(Elementos)**
  - **Maestría Total:** +20% **(Especialidades)**
  - **Arte de Sangre Demoníaca**
    - El usuario es capaz de tener un **Arte de Sangre Demoníaca**.
  - **Regeneración de Estado Vital:** 4.000 x Turno `〨Sangre〨`

  - **Recuperación de Aguante:** 4.000 x Turno `〨Sangre〨`
  - **Detección:** 4 `〨Sangre〨`
  - **Predicción:** 4 `〨Sangre〨`
  - **Alimentación Evolutiva**
    - Es necesario que el cuerpo devorado sea un **boss/jugador**.
      - **Porcentaje:** 20% x Cuerpo **(General)** `〨Sangre〨`
  - **Aumentos Pasivos**

**Demonio Bajo el Sol.** Los demonios son criaturas con varias desventajas. Todas estas desventajas se pueden curar si se utiliza la medicina de '**Lirio de Araña Azul**'.

- **Propiedades**
  - **Luz Solar**
    - Si entran en contacto con los rayos del sol, reciben una quemadura que inevitablemente les **ejecuta** las extremidades alcanzadas.
  - **Nichirin**
    - Las armas de tipo ‘**Nichirin**’ son el **doble** de efectivas contra estos, permitiendo que los daños provocados por estas contra un demonio sea el **doble**.
  - **Glicinias**
    - Las plantas de ‘**Glicinias**’ pueden impedir que se utilice cualquier cosa de esta raza mientras sigan en contacto con esta.
- **Requisitos de Aprendizaje**
  - **Rango de Ascensión:** Bajo.

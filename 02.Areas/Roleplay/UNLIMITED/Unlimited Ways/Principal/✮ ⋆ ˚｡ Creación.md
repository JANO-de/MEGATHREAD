# ✮ ⋆ ˚｡ Creación

![[image_(10).png]]

**✦ Creación.** El usuario será capaz de crear objetos los cuales tendrán un poder basado en el nivel de maestría que tenga el usuario con esta habilidad. Los objetos creados, en caso de tener estadísticas, desaparecen luego de un día fuera de rol. (**Las estadísticas que se pueden colocar, se reparten entre las stats mencionadas, no es esa cantidad por cada estadística.**)

- **Estadísticas**
  - **Suma:** 5.000 x Armamento **(???)** `〨Creación〨`
    - Entre **Fuerza Principal**, **Velocidad** y **Resistencia**.
  - **Suma:** 20% x Equipamiento **(???)** `〨Creación〨`
    - Entre **Fuerza Principal**, **Velocidad** y **Resistencia**.
- **Naturaleza**
  - **Karma-Mágico:** Sólido/Líquido/Gas/Sonido/Vibración/Luz/Espacio-Temporal/Entorno
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 5.000
  - **CD:** 0 Turnos

‌

**✦ Creación Replicada.** Es lo mismo que lo anterior pero con una leve diferencia. Esta habilidad solo puede usarse mientras se esté tocando otro objeto, lo que permitirá crear un objeto con la naturaleza, propiedades y efectos de ese objeto que se estaba tocando. El objeto creado durará **siete días fuera de rol**.

- **Estadísticas**
  - **Suma:** 5.000 x Armamento **(???)** `〨Creación〨`
    - Entre **Fuerza Principal**, **Velocidad** y **Resistencia**.
  - **Suma:** 20% x Equipamiento **(???)** `〨Creación〨`
    - Entre **Fuerza Principal**, **Velocidad** y **Resistencia**.
- **Naturaleza**
  - **Karma-Mágico:** ???
  - **Elemento:** Ninguno
- **Consumo**
  - **Aguante:** 10.000
  - **CD:** 0 Turnos

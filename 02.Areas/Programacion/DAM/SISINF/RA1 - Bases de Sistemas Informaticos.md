## Aplicaciones
- Tienen 6 capas que la forman.
	1. Presentacion
	2. Sesion
	3. Transporte
	4. Red
	5. Enlace
	6. Fisica

#### Capas Categorizadas
- Sistema Operativo
- Procesos y Memoria
- Almacenamiento y Permisos
- Red y Servicios

#### Proceso de desarrollo
1. Entender el equipo:
	1. Componentes
	2. Arranque
	3. Perifericos
	4. Topologia de red
2. Preparar el entorno:
	1. Instalacion
	2. Actualizacion
	3. Virtualizacion de sistemas operativos
3. Administrar recursos:
	1. Usuarios
	2. Permisos
	3. Procesos
	4. Almacenamiento
	5. Copias
4. Conectar y proteger:
	1. TCP/IP
	2. Servicios de red
	3. Acceso remoto
	4. Seguridad basica

## EJ-1 Diagnostico
> [!NOTE] 
> Una aplicacion funciona en el equipo pero no puede conectarse al servidor del aula. Elegir 3 comprobaciones, ordenarlas y justificar por que se realizaria la que se elige como primera.

 1. Comprobar que el servidor funciona correctamente, comprobar el cableado y la conexion al mismo.
 2. Comprobar la compatibilidad de la aplicacion con el servidor, y buscar dependencias fallidas.
 3. Comprobar que tenga permisos para levantar la aplicacion en el servidor, que haya almacenamiento y suficiente memoria para hacer que arranque.
